# 인물 그림

앱에 나오는 라이언, 소희, 제이크의 그림입니다. 맥 서버가 `/assets/<이름>`으로 앱에 보냅니다. 서버가 내주는 파일 이름은 `server/je_server/app.py`의 `ASSETS`에 있습니다.

## 쓸 수 있는 범위

- 이 그림들은 AI로 만들었고, 저장소의 [MIT 라이선스](../../LICENSE)에 들어가지 않습니다.
- 이 앱은 각자 자기 맥에 서버를 띄우고 자기 폰에서 쓰는 개인용입니다. 그림도 그렇게 이 앱을 자기가 쓸 때만 쓸 수 있습니다.
- 다른 앱, 서비스, 글, 영상에 쓰지 마세요. 자기가 만든 그림이라고 하지도 마세요.
