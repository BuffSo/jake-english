# 폰 없이 녹음을 서버에 보내 시험하기

> 작성: 2026-11-08 (feedback-explanation 카드)
> 학습자 목소리로 녹음을 만드는 명령과 이 맥의 경로, 주소는 비공개 메모에만 둔다.

폰으로 녹음하는 시험은 사용자의 시간이 든다. 에뮬레이터는 마이크에 말을 넣기 어렵다. 그래서 학습자 목소리로 녹음 파일을 만들고, 앱과 같은 요청으로 맥 서버에 보낸다. 받아쓰기, 따라 말했는지 가르기, 라이언의 답, 라이언의 목소리까지 실제로 돈다. 이 문서는 그 기준과 명령, 겪은 것을 담는다.

## 정한 기준

- **사용자 시험은 꼭 필요할 때만 부탁한다.** 사용자는 「내가 이걸 다 테스트하기에는 힘들어... 되도록이면 내가 개입해서 하는 수고는 반드시 필요할때만 요청 하도록 해」라고 했다(2026-11-08). 먼저 자동 시험, 실제 모델 호출, 이 문서의 녹음 시험으로 확인한다. 폰 화면도 에이전트가 adb로 직접 본다(`DEVENV_폰을_adb로_시험하기_20261108.md`). 사용자에게는 사람이 직접 말하거나 보고 골라야 하는 것만 부탁한다(`AGENTS.md` 「시험은 에이전트가 다 마친다」).
- **학습자 녹음은 학습자 목소리(제이크)로 만든다.** 라이언 목소리로 만들지 않는다(사용자, 2026-11-08).
- **녹음 문장은 지어낸다.** 대사를 그대로 말한 것, 낱말 하나를 바꾼 것, 대사를 말하다 한국어로 바꾼 것, 한국어 질문처럼 시험할 경우마다 하나씩 만든다.
- **사용자 기록에 시험을 섞지 않는다.** 역할극을 「이 상황 다시 하기」로 복사해 복사본에 보내고, 끝나면 복사본을 지운다. 지우지 않으면 시험한 시도가 「지난 상황」의 최근 기록으로 보인다.
- **스킬이 아니라 스크립트와 이 문서로 둔다.** 이 저장소에서만 쓰고, 목소리 만들기가 개인 환경에 기대기 때문이다(AI 추천을 사용자가 받아들임).

## 명령

맥 서버 폴더(`server/`)에서 돌린다.

1. **녹음을 만든다.** 이 맥의 음성 도구로 학습자 목소리 m4a를 만든다. 명령은 비공개 메모(`docs/private/mac-env.md` 「학습자 목소리로 시험 녹음 만들기」)에 있다. 다른 맥에서 흐름만 볼 때는 맥의 기본 음성으로 만들어도 된다.

   ```sh
   say -o probe.aiff "Could we move the meeting to Friday afternoon?"
   afconvert -f m4af -d aac probe.aiff probe.m4a
   ```

2. **시험할 역할극과 줄을 고른다.** 최근 역할극 열 개와 줄 번호가 나온다. 사용자가 연습한 대사라 화면에서만 본다.

   ```sh
   uv run python scripts/try_recordings.py --list
   ```

3. **보낸다.** 녹음 여러 개를 한 번에 보낼 수 있다. 모두 같은 복사본의 같은 줄에 차례로 간다. 그래서 둘째 녹음부터는 앞 시도가 「나아진 점」 후보에 들어간다.

   ```sh
   uv run python scripts/try_recordings.py <역할극 id> <줄 번호> a.m4a b.m4a [--mode turn|retry|practice|shadow] [--keep]
   ```

   - `--mode`는 앱의 연습 종류다. `turn`(역할극의 첫 차례, 기본), `retry`(다시 해 보기), `practice`(내 대사 연습), `shadow`(라이언 대사 따라 말하기). `shadow`만 라이언의 줄에 보내고, 나머지는 내 줄에 보낸다. 맞지 않으면 복사하기 전에 멈춘다.
   - 녹음마다 들린 말, 따라 말했는지, 라이언의 답, 끝 이벤트(다음 줄 번호, 짚은 수), 서버가 저장한 시간(받아쓰기, 첫 글자, 첫 소리, 전체)을 찍는다.
   - `--keep`은 복사본을 지우지 않고 그 id를 찍는다. 다 보면 데이터 폴더의 `roleplays/<id>`를 직접 지운다.

4. **녹음 파일을 지운다.** 학습자 목소리로 만든 소리다. 저장소 밖 임시 폴더에 만들고 시험이 끝나면 지운다.

- 스크립트는 `server/.env`의 `JE_HOST`, `JE_PORT`, `JE_TOKEN`, `JE_DATA_DIR`을 서버와 같은 방법으로 읽는다. 토큰은 화면에 찍지 않는다.
- 지금 도는 서버에 보낸다. 원래 폴더 서버(main의 코드)가 돌면 그 코드를 시험한다. 브랜치의 코드를 시험하려면 `DEVENV_맥서버_저절로_띄우기_20261107.md` 「카드가 서버를 시험할 때」대로 원래 폴더 서버를 멈추고 worktree 서버를 띄운다. 그동안 폰은 서버에 붙지 못하니 먼저 사용자에게 묻는다. 스크립트가 제대로 도는지만 볼 때는 서버를 멈출 필요가 없다.
- 복사본 지우기는 서버 API가 아니라 스크립트가 맥의 데이터 폴더에서 한다. 서버에는 지우는 경로가 없고, 시험만을 위해 폰이 부를 수 있는 경로를 늘리지 않으려는 것이다. 스크립트는 이름이 맞고 기록에 「복사한 원본」이 그 역할극으로 적힌 폴더만 지운다(`remove_copy`).

## 돈이 든다

라이언의 답은 Claude를 부른다. 녹음 하나에 한 번이다.

| 녹음 | 부르는 모델 | 한 번에 |
|---|---|---|
| 대사를 따라 말한 녹음 | 짧은 말 모델(지금 Haiku) | 0.03센트쯤 |
| 대사와 다른 녹음(선생님 라이언) | 글쓰기 모델(지금 Sonnet) | 0.7센트쯤 |

몇 개를 보낼지와 비용을 먼저 사용자에게 말한다(`AGENTS.md` 「새로 설치하거나 비용이 드는 일」). 위 값은 2026-11-08에 잰 것이다. Haiku 5.5는 백만 토큰당 입력 0.1달러, 출력 0.5달러, Sonnet 5.5는 2달러, 10달러다.

## 공개 파일에 옮기지 않는 것

- 출력의 대사, 들린 말, 라이언의 답은 터미널에서만 본다. 학습자 목소리 녹음과 그것을 받아쓴 글, 사용자가 연습한 대사는 공개 파일과 커밋 메시지에 쓰지 않는다(`REVIEW.md` 「공개 저장소 노출」, 「녹음 처리」).
- 가이드와 devlog에는 「낱말 하나를 바꾼 녹음은 그 낱말을 짚었다」처럼 무엇을 시험했고 어떻게 됐는지만 쓴다. 예를 들어야 하면 새로 지어낸 문장을 쓴다.

## 겪은 것

### 받아쓰기가 앞뒤 말을 보고 낱말을 고쳐 적는다 (2026-11-08)

- **증상:** R과 L의 소리 설명까지 서버에서 보려고, 대사의 R 낱말 하나를 비슷한 L 낱말로 바꿔 읽은 녹음을 만들었다. 받아쓰기는 그 낱말을 대사의 낱말로 적었고, 따라 말한 것이 되어 짚을 것이 없었다.
- **원인:** 받아쓰기에 대사를 힌트로 주지 않아도, 받아쓰기 모델이 문장의 앞뒤 말로 가장 그럴듯한 낱말을 고른다. 합성 녹음은 소리가 또렷해서 더 그렇다.
- **어떻게 하나:** 소리 하나를 바꾼 녹음으로는 소리 설명 길을 시험하기 어렵다. 라이언이 소리 설명을 말하는지는 맥이 찾은 것을 직접 넣어 실제 모델로 본다(`scripts/check_ryan_wording.py`, `PRONUNCIATION_따라말하기_짚기_20261106.md` 「라이언의 말을 고칠 때」). 녹음 시험은 낱말이 통째로 바뀐 경우(two 대신 three)와 한국어로 말한 경우에 쓴다.

### 이 방법으로 찾은 것 (2026-11-08, offscript-aside 카드)

- 대사 앞부분을 영어로 말하고 한국어로 바꾼 녹음을 보내자, 영어 받아쓰기가 한국어를 한글 그대로 적었다. 영어 낱말만 세어 대사와 맞는지 보던 서버가 이것을 따라 말한 것으로 쳤다. 폰 시험으로는 같은 말을 되풀이하기 어려운 경우였다.
- 영어 받아쓰기에 한글이 있으면 따라 말한 것으로 보지 않게 고쳤다(`server/je_server/engine.py`의 `attempt`). 같은 녹음을 다시 보내 선생님 라이언의 답이 나오는 것을 확인했다.

## 확인 방법

```sh
cd server
uv run pytest -q tests/test_try_recordings.py
```

- 시험 서버에 가짜 받아쓰기와 가짜 Claude를 두고 스크립트를 돌린다. 복사본에만 시도가 쌓이고 끝나면 복사본이 사라지는지, 원본에는 시도가 없는지, 소리 없는 녹음의 오류를 알리는지, 모드에 맞지 않는 줄은 복사하기 전에 멈추는지, 복사본이 아닌 폴더는 지우지 않는지 본다.
- 실제로 돌린 뒤에는 `--list`로 그 역할극의 복사본이 남지 않았는지 본다.
