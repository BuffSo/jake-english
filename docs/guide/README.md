# guide

분야별로 다음 작업이 따를 기준과, 구현하며 겪은 문제와 해결을 쓴다. 무엇을 쓰는지, 파일 이름, 공개 규칙은 `AGENTS.md` 「이 저장소에서 지키는 규칙」의 「겪은 문제와 해결」을 따른다. 규칙이 두 곳에서 어긋나지 않게 여기에는 다시 적지 않는다.

## 쓰는 법

- 다른 프로젝트에서도 참조한다. devlog나 ADR을 읽지 않아도 되게, 내용과 확인 방법을 가이드 안에 다 쓴다.
- 새 가이드를 쓰면 아래 「목록」에 한 줄 더한다.
