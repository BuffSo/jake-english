# guide

분야별로 다음 작업이 따를 기준과, 구현하며 겪은 문제와 해결을 쓴다. 규칙은 `AGENTS.md` 「이 저장소에서 지키는 규칙」의 「겪은 문제와 해결」에 있다.

## 파일

- 이름은 `<DOMAIN>_<주제>_YYYYMMDD.md`다. DOMAIN은 대문자 영어다.
- 다른 프로젝트에서도 참조한다. devlog나 ADR을 읽지 않아도 되게, 내용과 확인 방법을 가이드 안에 다 쓴다.
- 새 가이드를 쓰면 아래 「목록」에 한 줄 더한다.
- 공개된다. 개인 정보, 개인 환경, 참고 앱 이름을 쓰지 않는다.
