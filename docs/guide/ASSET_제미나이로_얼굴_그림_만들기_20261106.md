# ASSET 제미나이로 얼굴 그림 만들기

> 작성: 2026-11-06 (기다리는 동안 생각하는 얼굴, waiting-animation 카드)

앱 인물의 얼굴 그림을 제미나이 이미지 생성으로 만들며 정한 것과 겪은 문제다. 그림 파일은 공개 저장소에 넣지 않고 비공개 폴더에 둔다(PRD 열린 질문 8). 어떤 그림을 넣고 무엇을 골랐는지는 비공개 메모에 있다.

## 정한 것

- **새 그림은 새 채팅에서 만든다.** 큰 변화(얼굴, 그림체)는 같은 채팅에서 고쳐 달라고 하지 않고, 바뀐 조건을 처음부터 다 적어 새 채팅에서 다시 만든다(아래 문제 2).
- **표정만 바꿀 때는 기본 그림 하나를 올리고 고쳐 달라고 한다.** 「같은 사람, 머리, 옷, 배경, 그림체, 구도, 머리 크기와 위치, 9:16은 그대로, 표정만」처럼 지킬 것을 먼저 다 적는다. 표정마다 새 채팅에서 같은 기본 그림으로 한다. 앞 결과를 다시 고치면 조금씩 달라진 것이 쌓인다.
- **원하는 얼굴은 특징을 글로 적는다.** 참고 그림만 주면 흔한 얼굴 쪽으로 간다. 얼굴형, 턱, 눈썹, 눈, 코, 입을 항목마다 원하는 모습과 결과를 나란히 놓고 비교해, 다른 곳을 글로 적는다. 「넓히지 말 것」처럼 하지 말 것도 적는다. 이것으로 원하는 얼굴에 가장 많이 가까워졌다.
- **맥에서 할 수 있는 것은 맥에서 한다.** 위치 맞추기, 자르기, 두 그림의 중간 만들기는 제미나이에 다시 맡기지 않고 Pillow로 한다(아래 문제 3, 4). 다시 맡기면 얼굴이 또 바뀐다.
- **동그라미에 쓸 그림은 얼굴만 정사각형으로 잘라 둔다.** 그러면 앱은 그림 전체를 동그라미에 채우기만 하면 된다. 세로 그림을 쓰면 앱에 「그림 안의 얼굴 자리」 숫자를 둬야 한다(라이언의 듣는 얼굴이 그렇다).
- 받은 그림은 바로 비공개 폴더에 저장한다. 임시 폴더는 맥을 다시 켜면 지워진다.

## 문제 1: 그림체 참고로 넣은 다른 인물의 얼굴이 섞인다

- **증상:** 그림체를 맞추려고 다른 인물 그림 한 장을 함께 넣고, 요청 글에 「이 그림은 그림체만 참고, 다른 사람이다, 얼굴을 따라 하지 말 것」이라고 썼다. 그런데도 결과가 그 인물을 닮았다.
- **원인:** 이미지 생성은 넣은 그림 전체를 섞어 쓴다. 글로 「그림체만」이라고 해도 얼굴이 함께 들어간다.
- **고친 것:** 그 그림을 빼고 그림체는 글로 적었다(「실사형 3D, 매끈한 피부, 고른 스튜디오 조명, 사진도 납작한 만화도 아님」).
- **같은 실수를 막는 방법:** 그림체 참고 그림에는 사람 얼굴이 없는 것(배경, 물건)만 쓴다. 단순하게 그린 일러스트도 같다. 일러스트의 과장된 특징(굵은 선, 넓은 얼굴)이 결과에 그대로 나온다.

## 문제 2: 같은 채팅에서 고쳐 달라고 하면 거의 바뀌지 않는다

- **증상:** 「주름을 지우고 더 젊게」, 「변화가 너무 작다, 훨씬 세게」를 두 번 보냈다. 결과는 앞 그림과 거의 같았다(눈 밑만 조금 매끈해짐).
- **원인:** 같은 채팅에서는 앞 그림을 고치는 쪽으로 동작해, 앞 그림을 많이 지킨다.
- **고친 것:** 새 채팅에서 바뀐 조건(얼굴 특징, 나이, 피부)을 처음부터 다 적어 다시 만들었다.
- **같은 실수를 막는 방법:** 작은 손질(그림풍을 조금 더 실사로)만 같은 채팅에서 한다. 얼굴이나 나이를 바꿀 때는 새 채팅이다.

## 문제 3: 사진풍으로 갈수록 같은 인물로 보이지 않는다

- **증상:** 3D 느낌을 줄이려고 「실제 사진처럼」 요청한 판과 「조금 더 실사로」 고친 판이, 앞서 고른 3D 판과 다른 사람처럼 보였다.
- **원인:** 사진에 가까울수록 작은 차이가 다른 사람으로 보인다. 매끈하게 다듬은 그림은 차이를 덜 드러낸다.
- **고친 것:** 3D 판과 「조금 더 실사로」 고친 판은 같은 채팅의 고치기 결과라 구도가 똑같았다. 둘을 Pillow로 반씩 섞어(`Image.blend(a, b, 0.5)`) 그림풍만 딱 중간인 그림을 만들었고, 그것을 골랐다.
- **같은 실수를 막는 방법:** 그림풍을 고를 때 사진풍 끝까지 가지 않는다. 두 후보가 같은 그림을 고친 것이면, 다시 생성하지 말고 섞어서 중간을 만든다. 섞기 전에 위치가 같은지 본다(아래 확인 방법).

## 문제 4: 같은 기본 그림을 고쳐도 구도가 조금씩 다르다

- **증상:** 생각하는 표정 두 장을 같은 기본 그림에서 만들었는데, 한 인물은 두 번째 그림이 1.02배 크고 몇 픽셀 옮겨져 있었다. 그대로 번갈아 보여 주면 얼굴이 튄다. 기본 그림과 비교하면 두 장 모두 얼굴이 더 크고 아래로 내려와 있었다.
- **고친 것:** 두 그림 중 하나를 기준으로, 머리카락과 이마, 귀가 있는 네모 안에서 크기(0.94~1.06배)와 위치(±24픽셀)를 바꿔 가며 회색조 차이가 가장 작은 값을 찾았다(그림을 반으로 줄여 계산). 그 값으로 옮긴 뒤 같은 정사각형으로 잘랐다.
- **같은 실수를 막는 방법:** 번갈아 보여 줄 그림끼리는 반씩 섞은 그림을 만들어 눈으로 본다. 겹친 자국(눈, 머리 윤곽이 두 개)이 없으면 된다. 기본 그림과 맞출 필요는 없다. 번갈아 보여 주는 것은 생각하는 그림끼리다.

## 확인 방법

- 얼굴: 원하는 모습과 결과를 같은 높이로 나란히 놓고 얼굴형, 눈썹, 눈, 코, 입을 하나씩 비교한다.
- 위치: 두 그림을 반씩 섞어 겹친 자국이 없는지 본다.
- 동그라미: 정사각형 그림을 원 모양으로 가려 앱에서 보일 모습을 본다.
