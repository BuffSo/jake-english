# ADR-0007 집 밖에서는 Tailscale로 폰을 집의 맥에 잇는다

- 상태: 채택
- 날짜: 2026-11-05

## 배경

ADR-0001은 첫 판을 집 와이파이 안에서만 쓰고, 집 밖 연결은 ADR로 정하기 전에는 열지 않는다고 정했다. 2026-11-05 사용자가 「오늘 안에 외부에서도 폰으로 할 수 있게 하는 것」을 목표로 정했다.

지킬 것은 셋이다.

- 녹음과 목소리는 맥 밖의 저장소나 남의 서비스에 남기지 않는다(ADR-0001, `REVIEW.md` 「녹음 처리」).
- 맥 서버를 인터넷에 드러내지 않는다. 모든 기능은 토큰 같은 인증을 거친다(`REVIEW.md` 「맥 서버 보안」).
- 개인이 혼자 쓰는 앱이라, 돈이 들지 않거나 가장 적게 드는 쪽을 고른다(ADR-0006 「영향」).

## 검토한 안

1. **Tailscale.** 맥과 폰에 앱을 깔고 같은 계정으로 묶는다. 두 기기만 들어 있는 개인 망이 생기고, 폰은 어디서든 그 망 안의 주소로 맥에 붙는다. 개인 요금제는 무료다.
2. **공유기 포트 전달.** 집 공유기의 포트를 열어 맥 서버로 보낸다. 맥 서버가 인터넷 전체에 드러난다.
3. **공개 터널.** 터널 서비스가 맥 서버에 인터넷 주소를 붙여 준다. 주소를 아는 사람은 누구나 접속을 시도할 수 있고, 오가는 내용이 터널 회사 서버를 지난다.
4. **클라우드 서버로 옮기기.** 녹음이 맥 밖으로 나가고 돈이 든다. ADR-0006의 비용 순서에서 마지막이다.

## 판단

AI가 1을 추천했고, 사용자가 추천대로 정했다.

- 2와 3은 맥 서버를 인터넷에 드러낸다. 토큰 하나에 모든 것이 걸린다.
- 1은 망에 넣은 기기만 맥에 닿는다. 기기 사이의 내용은 끝에서 끝까지 암호화된다. 직접 잇지 못할 때는 Tailscale의 중계 서버를 지나지만, 그때도 암호화된 채로 지나서 중계 서버는 내용을 볼 수 없다.
- 1은 돈이 들지 않는다. 개인 요금제의 사용자 수와 기기 수는 이 앱에 넉넉하다. 2026-11-05에 본 정리 글 기준이며, 설치할 때 공식 페이지에서 다시 확인한다.

## 결정

- 맥과 갤럭시에 Tailscale을 깔고, 사용자의 계정 하나로 묶는다.
- 앱은 집 안에서도 밖에서도 맥의 Tailscale 주소로 맥 서버에 붙는다. 집 와이파이 주소로 따로 붙는 길은 두지 않는다(AI 판단). 주소가 하나면 집 안팎에서 앱 설정이 같다.
- 맥 서버를 인터넷에 여는 기능(Tailscale Funnel, 포트 전달, 공개 터널)은 쓰지 않는다.
- 토큰 인증은 그대로 둔다. Tailscale 망 안의 기기라도 토큰 없이는 기능을 쓸 수 없다.
- ADR-0001의 「첫 판은 집 와이파이 안에서만 연결한다」는 이 ADR로 바뀐다. 계산은 맥에서 한다는 나머지 결정은 그대로다.

## 영향

- 집 밖에서 쓰는 동안 맥이 켜져 있고 잠들지 않아야 한다. 맥의 잠자기 설정은 사용자가 바꾼다. 맥이 꺼져 있으면 앱은 지금 연습할 수 없다고 알린다(PRD 「사용 장면」).
- 녹음과 소리가 폰의 모바일 데이터로 오간다. 한 번의 녹음과 소리는 크지 않다.
- 맥의 Tailscale 주소, 기기 이름, 망 이름은 개인 환경이라 공개 파일에 쓰지 않는다. 비공개 메모에만 둔다. 앱 설정에도 저장소에 커밋하지 않는 파일로 넣는다.
- Tailscale 설치는 사용자가 2026-11-05에 허락했다. 계정 로그인은 사용자가 한다.
- `REVIEW.md` 「맥 서버 보안」은 이 ADR에 맞춰, Tailscale 밖으로 여는 설정을 지적하게 고친다.
