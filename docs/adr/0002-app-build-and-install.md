# ADR-0002 앱은 리액트 네이티브와 Expo로 만들고, 맥에서 빌드해 직접 설치한다

- 상태: 채택
- 날짜: 2026-11-03 (기록은 2026-11-04)

## 배경

앱은 사용자의 갤럭시(안드로이드)에서 쓴다. 다른 사람에게 배포하지 않고, 스토어에도 올리지 않는다. 나중에 아이폰에서 쓸 가능성은 남겨 둔다.

## 검토한 안

- **앱을 만드는 틀:** 리액트 네이티브와 Expo(타입스크립트). 다른 틀과 깊이 비교하지는 않았다.
- **빌드:** Expo 클라우드 빌드(EAS), 또는 맥에서 직접 빌드.
- **설치:** 플레이스토어, 또는 앱 파일(APK)을 폰에 직접 설치.

## 판단

첫 판 계획을 세울 때 사용자가 정했다. 이 기록은 그 결정을 옮긴 것이라, AI가 처음 추천한 안이 따로 남아 있지 않다.

- 리액트 네이티브와 Expo는 사용자가 써 보고 싶어 했다. 같은 코드로 나중에 아이폰 빌드도 할 수 있다.
- 클라우드 빌드는 코드가 밖으로 나가서 쓰지 않는다. 다만 이 이유는 저장소를 공개하기로 정하기(2026-11-04) 전의 것이다. 코드는 어차피 공개되므로, 다른 이유가 남아 있는지 사용자에게 확인한다. 확인하기 전까지 결정은 그대로 둔다.
- 배포하지 않으므로 스토어에 올리지 않는다.

## 결정

- 앱은 리액트 네이티브와 Expo, 타입스크립트로 만든다.
- 빌드는 맥에서 직접 한다. Expo 클라우드 빌드(EAS)는 쓰지 않는다.
- APK를 갤럭시에 직접 설치한다. 스토어에 올리지 않는다.

## 영향

- 맥에 안드로이드 빌드 도구가 필요하다. 없는 것은 설치 전에 사용자에게 묻는다.
- 폰에서 개발자 옵션과 USB 디버깅을 켜야 맥에서 설치할 수 있다.
- 구글이 스토어 밖 설치에도 개발자 확인을 요구하는 쪽으로 바꾸고 있다. 첫 APK를 만들 때 그 시점의 규칙을 다시 확인한다.
- 앱 고유 ID는 한 번 깔고 나면 바꾸기 어렵다. 그래서 첫 APK 빌드 전에 정한다(PRD 「열린 질문」).
