# ADR-0008 앱 고유 ID는 dev.jakeso.english로 한다

- 상태: 채택
- 날짜: 2026-11-05

## 배경

첫 APK를 빌드하기 전에 앱 고유 ID를 정해야 한다(PRD 열린 질문 7). Expo 설정의 `android.package`이고, 아이폰은 `ios.bundleIdentifier`다.

- 화면에 보이는 앱 이름은 언제든 바꿀 수 있다.
- 고유 ID는 한 번 깔고 나면 바꾸기 어렵다. 바꾸면 폰에 다른 앱으로 깔려 기록이 따로 논다. 스토어에 올리면 아예 바꿀 수 없다.
- 고유 ID는 앱 설정 파일에 들어가 공개 저장소에 드러난다.
- 서비스 이름은 비공개 메모에 검토할 안이 있다.

## 검토한 안

1. `dev.jakeso.english`: 사용자의 개인 도메인을 거꾸로 쓴 것 아래에 둔다.
2. `io.github.buffso.english`: 이미 공개된 GitHub 계정 이름 아래에 둔다.

안드로이드 고유 ID는 도메인을 거꾸로 쓰는 것이 관례다(예: 도메인 jakeso.dev는 dev.jakeso). 자기 도메인 아래에 두면 남의 앱과 겹치지 않는다.

## 판단

AI가 1을 추천했고, 사용자가 추천대로 정했다. 사용자는 도메인이 dev로 시작하는 까닭을 물었고, 위 관례를 듣고 정했다.

- 1은 개인 도메인 아래라 서비스 이름이 바뀌어도 어색하지 않다. 비공개 메모의 제안과도 같다.
- 1은 개인 도메인이 공개 저장소에 드러난다. 사용자는 이것을 알고 정했다.

## 결정

- 안드로이드 `android.package`와 아이폰 `ios.bundleIdentifier`를 `dev.jakeso.english`로 한다.
- 화면에 보이는 앱 이름은 저장소 이름을 따라 「Jake English」로 시작한다(AI 판단). 언제든 바꿀 수 있다.
- 서비스 이름은 서비스로 낼지 정할 때 따로 정한다(PRD 열린 질문 7, 비공개 메모 참고).

## 영향

- 첫 APK부터 이 ID로 빌드한다. 나중에 바꾸면 폰에 새 앱으로 깔린다.
- 앱 서명 열쇠는 ADR-0002대로 맥 밖으로 내보내지 않는다.
