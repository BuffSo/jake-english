# ADR-0012 맥 서버는 launchd 사용자 에이전트로 띄운다

- 상태: 채택
- 날짜: 2026-11-07

## 배경

- 맥 서버는 터미널에서 손으로 띄웠다(`uv run python -m je_server`). 맥을 다시 켜거나 서버가 죽으면 누가 다시 띄울 때까지 꺼져 있었다.
- 2026-11-07 아침 맥이 다시 켜진 뒤 서버가 꺼진 채 남아, 폰 앱이 「맥에 연결할 수 없어요」만 보였다.
- 서버는 맥의 Tailscale 주소에만 붙는다(ADR-0007). Tailscale 맥 앱은 사용자가 로그인한 뒤에만 돌고, 로그인 전에는 돌지 않는 한계는 그대로 두기로 했다(2026-11-05, `docs/guide/DEVENV_맥을_집밖_서버로_준비하기_20261105.md`).
- 카드(worktree 세션)들은 서버 코드를 시험할 때 원래 폴더의 서버를 끄고 worktree에서 띄운 뒤, 끝나면 원래 폴더에서 다시 띄웠다. 저절로 다시 띄우게 하면 이 방식이 바뀐다.

## 검토한 안

1. **launchd 사용자 에이전트(`~/Library/LaunchAgents`).** macOS에 들어 있는 장치다. 로그인할 때 띄우고(`RunAtLoad`), 죽으면 다시 띄운다(`KeepAlive`). 사용자 권한으로 돌아 사용자 폴더의 음성 환경, 받아쓰기 모델, 맥의 GPU를 지금처럼 쓴다. 관리자 암호가 필요 없다.
2. **launchd 시스템 데몬(`/Library/LaunchDaemons`).** 로그인 전에도 돈다. 하지만 관리자 권한으로 설치해야 하고, Tailscale이 로그인 전에는 돌지 않아 서버만 먼저 떠도 폰은 붙지 못한다.
3. **로그인 항목에 띄우는 스크립트.** 로그인할 때 한 번 띄울 뿐, 죽으면 다시 띄우지 않는다.
4. **따로 까는 관리 도구(homebrew services, pm2, supervisord 등).** 새로 깔아야 하고, 결국 launchd 위에서 돈다.

## 판단

AI가 1을 추천했고, 사용자가 추천대로 정했다(「ㅇㅋ」). 함께 정한 것:

- Tailscale이 서버보다 늦게 떠도 되게, 서버가 주소에 붙을 수 있을 때까지 기다렸다가 모델을 불러오게 고친다(AI 판단, 사용자가 받아들임). 5분 넘게 붙지 못하면 오류로 끝내는 것은 PR 리뷰 뒤 더했다(AI 판단). uvicorn은 앱을 준비한 뒤에 주소에 붙어서, 고치지 않으면 받아쓰기와 목소리를 다 불러온 뒤에 실패하고 launchd가 10초마다 다시 띄운다.
- 카드가 쓸 멈추기, 다시 켜기, 머지 뒤 다시 띄우기 명령을 스크립트에 둔다. 명령은 DEVENV 가이드에 쓰고, 카드가 늘 읽는 `AGENTS.md`에는 가이드를 가리키는 줄을 둔다(AI 추천, 사용자가 받아들임).

## 결정

- 서버는 launchd 사용자 에이전트 `dev.jakeso.english.server`로 띄운다. 이름은 앱 고유 ID(ADR-0008)를 따른다.
- 에이전트는 언제나 원래 폴더(`git worktree list`의 첫 줄)의 `server/`에서 `uv run python -m je_server`를 실행한다.
- 설치와 관리는 `server/scripts/autostart.sh`로 한다. 홈 폴더 경로가 든 에이전트 파일은 설치할 때 만들고, 저장소에는 스크립트만 둔다.
- 로그인할 때 띄우고 죽으면 다시 띄운다. 다시 띄우는 간격은 launchd 기본값(같은 작업을 10초에 한 번보다 자주 띄우지 않음)을 쓴다. 서버가 10초 넘게 돌다 죽으면 바로 다시 뜬다.
- `ProcessType`은 `Interactive`로 둔다. 비워 두면 launchd가 CPU와 디스크 읽기를 조금 줄인다(`man launchd.plist`). 학습자가 기다리는 받아쓰기와 목소리가 느려지면 안 된다.
- launchd는 셸 설정을 읽지 않는다. 그래서 설치할 때 `uv`, `ffmpeg`, `whisper-server`가 있는 폴더를 에이전트의 PATH에 넣는다.
- 로그는 전과 같이 `~/Library/Logs/jake-english/server.log`에 쌓는다. 서버가 남기는 내용(시간과 개수만)은 바뀌지 않는다.
- 서버를 시험하는 카드는 `stop`으로 멈추고, 끝나면 `start`로 되돌리고, 머지한 뒤에는 `restart`로 새 코드를 띄운다. `kill`과 `nohup`으로 원래 폴더 서버를 끄거나 띄우지 않는다.
- 로그인 전에는 띄우지 않는다. 2026-11-05에 정한 Tailscale의 한계와 같다.

## 영향

- 맥이 다시 켜지면 로그인할 때까지 집 밖에서 붙지 못한다(전과 같다). 로그인하면 Tailscale과 서버가 함께 뜬다.
- 맥이 「백그라운드 항목이 추가됨」을 알릴 수 있다. 시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램의 「백그라운드에서 허용」에서 이 항목을 끄면 서버가 뜨지 않는다.
- `kill`로 서버를 끄면 곧바로 다시 뜬다. 카드의 시험 방법이 바뀌었다(`AGENTS.md` 「세션과 worktree」, `docs/guide/DEVENV_맥서버_저절로_띄우기_20261107.md`).
- `JE_HOST`가 형식은 맞지만 틀린 주소면, 서버는 늦게 뜬 Tailscale과 구분하지 못해 기다린다. 5분 동안 붙지 못하면 오류를 남기고 끝나고 launchd가 다시 띄운다(PR #26 리뷰). 모델을 불러오기 전이라 가볍고, `status`의 `last exit code = 1`과 로그로 드러난다.
- `.env`가 틀려 서버가 시작하자마자 죽으면, launchd가 10초마다 다시 띄우며 같은 오류를 로그에 쌓는다. `autostart.sh status`의 `last exit code`와 로그 끝을 보고 고친 뒤 `restart`한다.
- homebrew가 도구 위치를 바꾸거나 저장소를 다른 폴더로 옮기면 `autostart.sh install`을 다시 실행한다.
- 머지로 의존 패키지가 바뀌면 `restart` 때 `uv run`이 잠금 파일대로 맞춘다.
