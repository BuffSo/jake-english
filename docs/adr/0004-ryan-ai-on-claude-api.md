# ADR-0004 라이언의 말은 외부 API(Claude)로 만든다

- 상태: 채택
- 날짜: 2026-11-05

## 배경

라이언은 이 앱의 선생님이다(PRD 「목소리와 역할」). 라이언이 하는 말은 AI가 만든다.

- 따라 말하기(첫 판): 듣기 팁, 녹음 평가, 칭찬
- 말하기(그다음): 영어 대화 상대, 말이 막혔을 때의 도움, 사용자가 설명한 상황을 즉석에서 만들기, 대화 뒤 고쳐 주기

ADR-0001은 이 AI를 맥 서버가 부르고 앱은 부르지 않는다고 정했다. 맥 안의 모델로 할지 외부 API로 할지, 외부로 보낸다면 무엇을 보내도 되는지는 이 ADR로 미뤘다.

기능마다 필요한 속도가 다르다.

- 듣기 팁은 장면을 준비할 때 미리 만들어 둘 수 있다. 속도와 상관없다.
- 녹음 평가는 몇 초 안에 와야 한다(PRD 「실패로 볼 것」 2, 열린 질문 2).
- 대화 상대와 말이 막혔을 때의 도움은 실시간이다.

품질도 중요하다. 평가가 틀리거나 같은 녹음에 매번 다르게 말하면 실패다(PRD 「실패로 볼 것」 1). 대화 상대는 사용자의 반응에 맞춰 대화를 자연스럽게 이어 가야 한다.

맥에는 맥 안에서 돌릴 수 있는 27B 언어 모델이 이미 있다. 그런데 맥은 받아쓰기 모델과 라이언 목소리 모델도 돌린다. 셋은 메모리와 GPU를 나눠 쓴다. 셋을 함께 돌렸을 때 얼마나 느려지는지는 재 보지 않았다.

## 검토한 안

1. **외부 API(Anthropic의 Claude)를 쓴다.** 맥에서 글을 Anthropic에 보내고 답을 받는다.
2. **맥 안의 모델을 쓴다.** 이미 깔린 27B 모델을 Ollama로 돌린다. 글이 맥 밖으로 나가지 않고, 쓰는 만큼 드는 돈이 없다.
3. **둘을 섞는다.** 미리 만드는 듣기 팁은 맥 안의 모델로, 실시간인 평가와 대화는 외부 API로 한다. 또는 외부 API를 쓰다가 인터넷이 끊기면 맥 안의 모델로 대신한다.

### 확인한 사실 (2026-11-05)

Anthropic의 공식 문서에서 확인했다. 정책과 가격은 바뀔 수 있으니, 기능 스펙에서 모델을 고를 때 다시 확인한다.

- **학습:** API로 보낸 입력과 출력은 기본으로 모델 학습에 쓰지 않는다([Is my data used for model training?](https://privacy.claude.com/en/articles/7996868-is-my-data-used-for-model-training)).
- **보관:** 받은 지 30일 안에 Anthropic 서버에서 지운다. 사용 정책을 어긴 것으로 자동 판정된 입력과 출력은 최대 2년 남는다. 보관하지 않는 계약(zero data retention)은 Anthropic의 승인을 받아야 한다([How long do you store my organization's data?](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data), 2026-07-01 판).
- **가격:** 백만 토큰당 입력/출력이 Haiku 5.5는 0.10/0.50달러(입력 10만 토큰 이하), Sonnet 5.5는 2/10달러, Opus 5.5는 4/20달러다([Pricing](https://platform.claude.com/docs/en/about-claude/pricing)).
- **같은 답을 고정할 수 없다:** API 버전 2026-10-21부터 `temperature`, `top_p`, `top_k`를 보내면 모든 모델이 400 오류를 돌려준다. 그래서 같은 입력에 같은 답이 나오게 설정으로 고정할 수 없다([Versions](https://platform.claude.com/docs/en/api/versioning)). 맥 안의 모델은 온도를 0으로 두고 seed를 정하면 같은 답을 낼 수 있다(일반적인 사실이고, 이 맥에서 시험하지 않았다).
- **생각하는 단계:** Opus 5.5는 답하기 전에 생각하는 단계를 끌 수 없고, effort(기본 `medium`)를 낮춰 줄일 수만 있다([Opus 5.5 migration guide](https://platform.claude.com/docs/en/models/opus-5-5/migration-guide)). Sonnet 5.5는 `thinking: {"type": "between_tools"}`로 끌 수 있고, 이것은 effort `low`, `medium`, `high`에서만 된다([Sonnet 5.5 migration guide](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide)). 생각하는 단계가 길면 첫 글자가 늦게 나온다.

## 판단

- AI는 1을 추천했다. 이유는 셋이다. PRD 세션(2026-11-04)도 같은 안을 같은 이유로 추천했다. 그 기록은 PRD와 devlog에는 없고, 그 세션이 이 일을 넘기며 남긴 글에 있다.
  - 속도와 품질이 낫다(AI 판단, 재 보지 않았다).
  - 녹음은 여전히 맥 밖으로 나가지 않는다. 나가는 것은 글뿐이다.
  - ADR-0001에 따라 AI 호출이 맥 한곳에 모이므로, 나중에 바꾸기 쉽다.
- 사용자는 Anthropic에 무엇을 보내는지 먼저 들었다. 본보기 문장, 받아쓴 글, 강세 분석 결과, 대화 글이다. 위 「학습」, 「보관」 정책(30일, 위반 판정 때 2년)도 들었다. 그리고 보내도 된다고 정했다.
- 사용자는 속도를 걱정했다. 맥 안에서 바로 답하는 것보다 Anthropic에 보냈다 받는 것이 느리지 않느냐는 것이다. AI는 아래처럼 판단했다(모두 재 보지 않은 판단이다).
  - 맥에서 Anthropic까지 다녀오는 시간은 보통 0.5초 안쪽이라, 답을 만드는 시간에 비하면 작다.
  - 답을 만드는 속도는 클라우드 모델이 맥 안의 27B 모델보다 대개 몇 배 빠르다. 맥 안의 모델은 대화 기록이 길어지면 그 글을 읽는 데도 시간이 든다. Ollama가 한동안 쓰지 않은 모델을 메모리에서 내리면 다시 불러오는 데 몇 초가 더 든다.
  - 외부 API를 쓰면 맥은 받아쓰기와 라이언 목소리만 맡는다. 셋을 함께 돌릴 때보다 받아쓰기와 목소리가 빨라진다.
  - 기다리는 시간의 대부분은 라이언 목소리를 만드는 데 들 것이다. 답을 받으면서 첫 문장부터 목소리로 넘기면 줄일 수 있다.
- AI는 두 안을 같은 문장으로 재 보자고도 제안했다. 사용자는 재지 않고 추천대로 정했다. 그래서 속도는 기능 스펙에서 잰다(아래 「영향」).
- 3은 고르지 않았다(AI 판단). 두 체계를 함께 만들고 맞춰야 한다. 듣기 팁도 틀리면 잘못 배우므로, 미리 만든다고 품질을 낮출 수 없다.
- 위 「같은 답을 고정할 수 없다」는 사용자가 정한 뒤 PR 리뷰에서 나온 사실이다. 이 점만은 2가 낫다. AI는 그래도 결정을 바꿀 까닭은 아니라고 본다.
  - 맥 안의 모델은 같은 답을 낼 수 있을 뿐, 맞는 답을 낸다는 뜻은 아니다.
  - 무엇을 짚을지 맥의 분석이 정하게 하면, 모델이 바뀌어도 짚는 곳은 같다(아래 「영향」).
  - 사용자에게는 PR에서 알렸다.
- AI가 추천한 안과 사용자가 정한 안이 같다.

## 결정

- 라이언의 말은 모두 외부 API인 Anthropic의 Claude로 만든다. 듣기 팁, 녹음 평가, 칭찬, 대화 상대, 말이 막혔을 때의 도움, 상황 만들기, 대화 뒤 고쳐 주기가 모두 해당한다.
- API는 맥에서 도는 프로그램(맥 서버, 장면 준비 도구)만 부른다. 폰 앱은 부르지 않는다(ADR-0001). 장면 준비 도구까지 넣은 것은 ADR-0001의 「맥 서버가 부른다」를 「맥에서 부른다」로 읽은 것이다(AI 판단). API 키는 맥에만 두고, 앱과 저장소에 넣지 않는다.
- Anthropic에 보내도 되는 것:
  - 본보기 문장과 장면의 대본
  - 사용자 녹음을 받아쓴 글
  - 강세를 분석한 결과. 낱말과 음절 단위의 판정, 그리고 그 근거가 되는 낱말과 음절 단위의 수치만 보낸다(AI 판단).
  - 대화 글: 사용자가 영어로 한 말, 말이 막혔을 때 한국어로 한 질문, 사용자가 직접 설명한 상황
  - 위 글로 만든 라이언의 말(평가, 고쳐 주기, 대화)
- Anthropic에 보내지 않는 것:
  - 녹음 소리, 목소리 파일, 복제 목소리의 기준 녹음
  - 소리를 되살리거나 목소리의 특징을 담은 값. 스펙트로그램 그림, 파형, 짧은 구간마다 잰 음높이와 세기 같은 것이다(AI 판단).
  - 기능에 필요하지 않은 것. 파일 경로나 기기 정보 같은 것이다(AI 판단).
- 대화 상대와 말이 막혔을 때의 도움은 답을 받으면서 첫 문장부터 라이언 목소리로 넘긴다(AI 추천을 사용자가 받았다). 녹음 평가를 어떤 모양으로 받아 말할지는 따라 말하기 스펙에서 정한다(아래 「영향」).
- 어느 기능에 어느 모델을 쓸지는 기능 스펙에서 정한다.
- 맥 안의 모델은 지금 쓰지 않는다.

## 영향

- 녹음은 맥 밖으로 나가지 않는다(ADR-0001 그대로). 받아쓴 글과 대화 글은 Anthropic에 가서 30일까지 Anthropic 서버에 남을 수 있다. 사용 정책 위반으로 판정되면 2년까지 남는다. `REVIEW.md` 「녹음 처리」의 「받아쓴 글이 ADR이 허용하지 않은 곳으로 나가는 것」은 위 「보내도 되는 것」과 「보내지 않는 것」을 기준으로 본다.
- 말하기 연습에서 사용자가 하는 말에는 실제 생활 이야기가 들어갈 수 있다. 그 글도 Anthropic에 간다. 사용자가 이것을 알고 정했다.
- **평가가 매번 같은지는 모델 설정으로 지킬 수 없다**(위 「같은 답을 고정할 수 없다」). 「실패로 볼 것」 1을 막는 방법은 따라 말하기 스펙에서 정한다. AI가 생각하는 방법은 둘이다.
  - 무엇을 짚을지는 맥의 분석(받아쓰기 비교, 강세 분석)이 정하고, Claude는 그것을 라이언의 말로 옮기기만 한다.
  - 같은 녹음의 평가는 저장해 두고 다시 쓴다.
- 소희의 통역 글(영어를 한국어로 옮기기)은 이 ADR의 범위(라이언의 말) 밖이다. 옮길 글은 이미 「보내도 되는 것」 안에 있다. 그래서 AI는 같은 API로 만드는 것을 추천한다. 따라 말하기 스펙에서 정한다.
- 라이언의 말을 만들려면 맥이 인터넷에 연결되어 있어야 한다. 연결이 끊기거나 API가 실패하면, 앱은 지금은 평가나 대화를 할 수 없다고 알린다(AI 판단). 맥 안의 모델로 대신하는 것(안 3)은 실제로 불편해지면 다시 정한다.
- 쓰는 만큼 돈이 든다. Haiku나 Sonnet이면 대화 한 턴에 1센트가 안 된다(AI 추정). 생각하는 단계를 끄고, 입력 약 2천 토큰과 출력 약 100토큰으로 셈했다. 생각하는 단계의 글도 출력 값으로 매겨지고, 한국어 평가 글은 이보다 길다. API 키를 받는 일과 시험 호출처럼 돈이 드는 일은 하기 전에 사용자에게 묻는다(`AGENTS.md`).
- 2026-11-08 짧은 말 모델이 맡던 세 일(라이언 평가, 소희 통역, 제이크 추천)을 Haiku와 Sonnet으로 견줬다. 일마다 결과가 달라 추천만 Sonnet으로 바꾸고 설정도 따로 두었다(`JE_CLAUDE_RECOMMEND`, 사용자 결정). 같은 짧은 말이라도 일마다 모델을 따로 고를 수 있다. 근거는 말하기 스펙 「기다리는 시간과 모델」과 `docs/guide/PROMPT_일마다_모델_견주기_20261108.md`에 있다.
- 속도는 재 보지 않았다. 녹음 평가가 몇 초 안에 오는지는 따라 말하기 스펙을 쓸 때 잰다(PRD 열린 질문 2). 실시간 기능에는 첫 글자가 빨리 나오는 모델을 고른다.
- AI 호출이 맥 한곳에 모여 있다. 나중에 맥 안의 모델이나 다른 서비스로 바꾸게 되면 그 부분만 바꾼다. 그때는 이 ADR을 「대체됨」으로 바꾸고 새 ADR을 쓴다.
