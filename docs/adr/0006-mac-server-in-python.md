# ADR-0006 맥 서버는 파이썬(FastAPI)으로 만들고, 앱과 한 저장소에 둔다

- 상태: 채택
- 날짜: 2026-11-05

## 배경

말하기 연습 스펙(`docs/superpowers/specs/2026-11-05-speaking-practice-design.md`)을 쓰면서, 맥 서버를 어떤 언어로 만들지 정해야 했다. 맥 서버는 앱이 보기에 백엔드 서버다(ADR-0001). 맡는 일은 아래와 같다.

- 앱과 주고받는 API
- 라이언의 말을 만드는 Claude 호출(ADR-0004)
- 받아쓰기(whisper.cpp)
- 라이언과 제이크 목소리(Qwen3-TTS)
- 발음 사전(CMUdict)으로 대사와 받아쓴 글의 소리 비교
- 녹음과 기록 저장

언어를 가르는 것은 목소리다.

- Qwen3-TTS는 파이썬 라이브러리로만 돈다. 맥의 음성 합성도 이미 파이썬으로 돌고 있다.
- 2026-11-05 강세 시험에 쓴 도구(MFA, Praat를 부르는 parselmouth)도 파이썬이다. 잰 값을 남기는 일(MVP 뒤)에 다시 쓴다.
- whisper.cpp는 따로 도는 실행 프로그램이라 어느 언어에서도 부를 수 있다. CMUdict는 데이터 파일이라 어느 언어에서도 읽을 수 있다.
- 저장소에 있는 Node 코드는 커밋 전 자동 검사 스크립트뿐이다.

사용자가 가장 많이 쓰는 백엔드 틀은 NestJS(타입스크립트)다.

ADR-0001은 나중에 배포하면 맥 서버 자리에 클라우드 서버를 끼울 수 있다고 적었다. 사용자는 나중에 서버로 옮길 생각이 있다.

## 검토한 안

1. **파이썬 하나로 만든다.** 웹 틀은 FastAPI를 쓴다.
2. **NestJS와 파이썬을 함께 쓴다.** API, 대화, 기록, Claude 호출은 NestJS가 맡고, 목소리 같은 소리 처리만 파이썬 프로그램이 맡는다. 둘은 맥 안에서 서로 부른다.

저장소는 앱과 서버를 한 저장소에 두는 안과 따로 두는 안을 견줬다.

## 판단

AI는 1과 한 저장소를 추천했고, 사용자가 추천대로 정했다. 사용자는 주력이 NestJS지만 파이썬 백엔드를 만들어 보는 것도 좋다고 했다.

- 2는 익숙한 NestJS로 짤 수 있다. 하지만 프로그램 둘을 띄우고 서로 잇는 일이 늘어 MVP가 늦어진다. 빨리 만들어 보고 고치기로 한 첫 판(PRD)에 맞지 않는다.
- 한 저장소에 두면 API를 바꿀 때 앱과 서버를 한 PR에서 같이 고칠 수 있다. 커밋 scope에 이미 `app`과 `server`가 있다(`AGENTS.md`).
- AI는 처음 물을 때 「받아쓰기, 라이언 목소리, 발음 사전이 모두 파이썬」이라고 했다. 받아쓰기와 발음 사전은 언어와 상관없어 바로잡았다. 결론은 목소리 하나로도 같다.

## 결정

- 맥 서버는 파이썬으로 만들고, 웹 틀은 FastAPI를 쓴다.
- 앱(ADR-0002)과 맥 서버는 이 저장소 하나에 둔다. 폴더는 `app/`과 `server/`로 나눈다(AI 판단).
- 파이썬 버전, 패키지 관리 도구, 시험 도구는 계획에서 정한다.

## 영향

- 앱(타입스크립트)과 서버(파이썬)의 언어가 달라, API 모양이 두 곳에 따로 생긴다. 서로 어긋나지 않게 하는 방법(예: FastAPI가 만드는 API 설명에서 앱 쪽 타입을 만들기)은 계획에서 정한다.
- 파이썬과 FastAPI 같은 새 설치는 계획 단계에서 사용자에게 먼저 묻는다(`AGENTS.md` 「새로 설치하거나 비용이 드는 일」).
- 서버를 어디서 돌릴지는 돈이 들지 않거나 가장 적게 드는 쪽으로 고른다. 개인이 혼자 쓰는 앱이기 때문이다(사용자 판단, 2026-11-05). AI가 추천하고 사용자가 받아들인 순서는 아래와 같다.
  1. 맥을 계속 서버로 쓴다. 서버 비용이 없고, 돈은 Claude API를 쓴 만큼만 든다.
  2. 집 밖에서 쓰고 싶어지면, 폰이 어디서든 집의 맥에 붙게 하는 무료 연결 도구(예: Tailscale 개인 요금제)를 더한다. 녹음은 맥 밖으로 나가지 않는다. 설치 전에 묻고, 집 밖 연결은 ADR을 따로 쓴다(ADR-0001).
  3. 맥을 끈 채로도 써야 할 때만 클라우드로 옮긴다.
- 클라우드로 옮기면, 받아쓰기와 목소리 모델은 GPU가 있는 서버에서 돌려야 한다. 맥은 칩 안의 GPU로 이 모델을 돌린다. GPU가 없는 서버에서는 답이 크게 늦어질 것으로 짐작한다(재 보지 않았다).
  - 쓸 때만 켜지고 쓴 초만큼 내는 GPU 서비스가 후보다. 매달 무료 크레딧을 주는 곳(예: Modal 무료 요금제. 2026-11-05에 본 정리 글 기준 한 달 30달러)이면, 혼자 쓰는 양은 돈이 거의 들지 않을 수 있다(짐작). 쉬다가 처음 부르면 모델을 올리느라 기다리는 시간이 생긴다.
  - 옮기면 녹음이 맥 밖으로 나간다. ADR-0001을 새 ADR로 대체하고, 그때 공식 페이지에서 서비스와 가격을 다시 확인한다.
  - 파이썬은 그런 GPU 서비스에서 흔히 쓰는 언어라, 옮길 때 이 결정을 다시 하지 않아도 될 것으로 본다(AI 판단).
