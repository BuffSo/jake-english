# ADR-0014 시험은 GitHub Actions에서도 돌린다(APK는 만들지 않는다)

- 상태: 채택
- 날짜: 2026-11-11

## 배경

- 지금까지 시험은 카드가 맥에서 돌리고, 결과를 PR 본문 「테스트 체크리스트」에 적었다(`AGENTS.md` 「시험은 에이전트가 다 마친다」). 그 적은 글 말고는 시험이 돈 것을 보여 주는 것이 없었다.
- 저장소를 공개하기 전에, 처음 보는 사람도 시험이 도는지 볼 수 있게 하려 한다. 또 사람이 아닌 장치가 PR마다 같은 시험을 새 환경에서 돌리면, 맥에만 있는 것(비공개 파일, 맥의 도구, 다른 패키지를 따라 깔린 패키지)에 기댄 시험이 드러난다.
- 맥 밖의 서비스에서 이 저장소의 코드를 돌리는 첫 결정이라 ADR로 남긴다.

## 검토한 안

1. **맥에서만 돌린다.** 지금 그대로다. 돈이 들지 않지만, 바깥에서 볼 수 있는 기록이 없다.
2. **GitHub Actions에서 시험만 돌린다.** 서버 pytest, 앱 jest와 tsc, 커밋 전 검사와 git 훅 시험. APK는 만들지 않는다. 저장소가 이미 GitHub에 있어 새 계정이 필요 없다.
3. **GitHub Actions에서 APK까지 만든다.**
4. **다른 CI 서비스.** 새 계정과 연결이 필요하다.

러너와 돌리는 때도 견줬다.

- 러너: 2코어 `ubuntu-latest`(분당 $0.006)와 1코어 `ubuntu-slim`(분당 $0.002). 둘 다 GitHub의 기본 러너이고 유료 전용 러너가 아니다.
- 돌리는 때: 모든 PR과 main push, 또는 그 부분(서버, 앱, 검사 스크립트)이 바뀐 PR과 main push만.

## 판단

- main 세션이 2안을 추천했고, 사용자가 정했다(「ㅇㅋ」, 2026-11-11).
- 비용: 비공개인 동안은 사용자 계정에 들어 있는 Actions 몫(GitHub Free는 월 $12, 2코어 리눅스로 약 2,000분)에서 빠지고, 작업마다 분 단위로 올려 센다. 그래서 카드가 바뀐 부분만 돌게 나누고 1코어 러너를 골랐다(AI 판단). 공개로 바꾸면 기본 러너는 무료다.
  - 1코어에서 처음 잰 시간(2026-11-11): 서버 2분 22초(ffmpeg 설치 1분, pytest 69초), 앱 1분 35초(캐시 없는 npm ci 48초, jest 16초, tsc 9초), 훅 30초. 올려 세면 3분, 2분, 1분이다.
  - 첫 주(PR 80개: 서버를 바꾼 것 46, 앱 39, 훅 2, 문서만 22) 속도로 PR마다 push 세 번과 머지 한 번씩 돈다고 어림하면, 바뀐 부분만 1코어로 돌려 한 달 $6~7쯤이다. 2코어로는 $12를 넘고, 모든 PR에서 셋을 다 돌리면 1코어로도 넘는다.
- 3안은 ADR-0002의 이유(앱 서명 열쇠가 맥 밖으로 나가지 않는다, 고칠 때마다 바로 빌드한다)가 그대로라 하지 않는다.
- 4안은 2안보다 나은 점이 없다.

## 결정

- `.github/workflows/`에 워크플로 셋을 둔다. 하나에 작업 하나다.
  - `test-server.yml`: 우분투 저장소의 ffmpeg를 깔고, `server/`에서 `uv sync --frozen`, `uv run --frozen pytest -q`. `server/`, `contract/`가 바뀔 때.
  - `test-app.yml`: `app/`에서 `npm ci`, `npm test`(jest), `npm run typecheck`(tsc). `app/`, `contract/`가 바뀔 때.
  - `test-hooks.yml`: `node --test 'scripts/**/*.test.mjs'`. `scripts/`, `.githooks/`가 바뀔 때.
  - 각 워크플로 파일 자신이 바뀔 때도 돈다.
- PR과 main push에서 돈다. 같은 브랜치에 새 push가 오면 앞 실행을 멈춘다. 러너는 `ubuntu-slim`이고, 작업마다 시간 제한(5~10분)을 둔다. npm과 uv는 캐시를 쓴다.
- 비공개 파일(`docs/private/`, `.env`)과 키는 넣지 않는다. GitHub secret을 쓰지 않는다. 실제 Claude, 받아쓰기, 음성 합성을 부르는 시험은 지금처럼 가짜로 대신하거나 건너뛴다. 비공개 금지어 목록도 넣지 않는다. 훅 시험은 임시 저장소마다 지어낸 목록을 만들어 돈다.
- 유료 러너와 외부 서비스(커버리지 서비스 등)는 쓰지 않는다.
- 맥에서 하는 시험(실제 모델 호출, 학습자 목소리 녹음, 폰 화면)은 그대로 카드가 한다. Actions는 그것을 대신하지 않는다.

## 영향

- ADR-0002와의 관계: ADR-0002는 Expo 클라우드 빌드(EAS)를 쓰지 않고 맥에서 빌드하기로 했다. 이 결정은 시험만 돌리고 빌드는 하지 않으므로 ADR-0002를 바꾸지 않는다.
- 이 저장소의 코드가 GitHub의 러너에서 돈다. 공개할 코드라 새로 나가는 것은 없다. 녹음, 키, 비공개 파일은 저장소에 없어 러너에도 가지 않는다.
- 들어 있는 몫을 다 쓰면: 결제 수단이 없는 계정은 그달의 실행이 막히고 돈은 나가지 않는다. 결제 수단이 있으면 넘는 만큼 분당 값이 청구된다. 실행 시간은 PR 본문이나 devlog에 적어 두고, 몫이 빠듯하면 돌리는 때를 더 줄인다.
- 액션은 판 번호가 아니라 커밋 해시로 고정했다(주석에 판 번호). 새 판으로 올릴 때 해시를 바꾼다.
- 시험이 맥의 도구나 비공개 파일에 기대면 Actions에서 깨진다. 그런 시험은 지금처럼 그것이 없으면 건너뛰게 쓴다(예: `test_stress_features.py`는 `JE_MFA_ENV`가 없으면 건너뛴다).
  - 서버가 쓰는 ffmpeg는 우분투 저장소에서 깐다. 처음 돌렸을 때 ffmpeg가 없어 서버 시험 229개가 실패했다. 서버 README에도 준비물로 적었다.
  - 맥과 우분투에서 도구가 깔리는 폴더가 다르다. launchd 설치 스크립트 시험 하나가 「ffmpeg가 시스템 폴더에 없다」에 기대 우분투에서 실패해, 시스템 폴더에 있는 도구는 건너뛰게 고쳤다. 그래서 Actions에서는 건너뛰는 시험이 하나 더 많다(5개).
- 서버가 직접 import하는 `pydantic`과 `httpx2`를 `server/pyproject.toml`에 넣었다. 새 환경에서 깔 때 다른 패키지를 따라 깔리는 것에 기대지 않게 했다.
