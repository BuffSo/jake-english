## 바로잡은 것

- **세 줄을 펼치면 파란 카드가 한 겹 더 들어갔다.** 지금 말할 줄을 파란 말풍선에 넣었는데, 펼친 세 줄은 원래 같은 파란 카드였다. 여백이 두 번 생기고 줄이 좁아졌다. 에뮬레이터 화면을 찍어 보고 찾았다. 말풍선 안에서는 카드 없이 그리게 했다(`ThreeLineView`의 `bare`). 글로 그린 화면 그림으로는 보이지 않던 것이라, 화면을 바꾸면 실제 화면을 한 번 찍어 본다.
- **리뷰 점수가 실제 문제를 낮게 봤다.** 버그 리뷰어는 「기다림이 나타날 때 바로 스크롤하면 그 위에서 멈출 수 있다」고 짚었지만, 점수 에이전트는 렌더러가 배치를 먼저 반영한다고 보고 25점을 줬다. 안드로이드 소스(`MountItemDispatcher.kt`)는 뷰 명령을 먼저 실행한다. 점수만 보고 넘기지 않고 소스로 확인한 뒤 고쳤다. `REVIEW.md`는 고치지 않았다. 리뷰가 놓친 것이 아니고, 이 저장소만의 지적 항목도 아니다. 겪은 문제와 막는 방법은 가이드 APP에 썼다.
- **그림 가이드와 다른 방법을 골랐다.** 그림 가이드는 동그라미에 쓸 그림을 얼굴만 정사각형으로 잘라 두라고 한다. 이번에는 할 일 파일대로 제이크 기본 얼굴(세로 그림)을 그대로 내주고, 라이언 듣는 얼굴처럼 앱에 얼굴 자리 값을 두었다(AI 판단). 그림을 바꾸면 앱의 값도 바꿔야 한다. 말하기 스펙 「상황 정하기」 3에 적었다.
