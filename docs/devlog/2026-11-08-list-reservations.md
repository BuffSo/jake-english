## 바로잡은 것

- **스펙이 지키지 않은 것을 적었다:** 「더한 대본」에 「대본이 말하는 값은 목록 설명에도 적었다」고 썼다. 그런데 호텔 설명은 「높은 층 방을 부탁한다」에서 끝나 12층이 없었고, 식당 설명에는 대기 명단의 이름이 없었다. 계획의 시험은 2박, 킹 침대, 30분, 바만 확인했다. 스펙 문장은 사용자가 정한 값 목록(12층과 이름 포함)을 보고 썼고, 설명은 그 전의 초안 그대로였다. PR 리뷰의 스펙 축과 브랜치 최종 리뷰가 같은 것을 찾았다. 두 값을 설명에 넣고 시험이 확인하게 했다. 같은 손질로, 호텔 설명에서 「직원이」가 쉼표 뒤까지 이어져 직원이 높은 층을 부탁하는 것처럼 읽히던 것도 고쳤다. 대본 값을 바꾸거나 더할 때는 설명과 그 시험의 낱말 목록을 함께 본다.
- **지난 기록 맞대기가 같은 문장만 봤다:** 글자까지 같은 문장만 셌다. 낱말 하나를 바꾼 줄이나 기록에서 온 지명은 0으로 나온다. PR 리뷰가 짚었다(50점). 낱말 넷, 다섯, 여섯이 이어진 것과 지명과 값 열 개를 다시 맞대 보았다. 다섯과 여섯은 0이었다. 넷은 흔한 말 1이었다. 지명과 값은 기록에 하나도 없었다. 목록 대본을 더할 때는 문장만이 아니라 낱말이 이어진 것과 지명도 맞대 본다.
- **커밋 둘이 한 커밋으로 섞였다:** 리뷰 수정의 첫 커밋이 제목 길이(72자 넘음)로 commit-msg 훅에 막혔다. 다음 문서 커밋을 `&&` 없이 새 줄로 이어 써서 그것이 돌았고, 남아 있던 코드 스테이징까지 문서 커밋에 들어갔다. push 전이라 그 커밋을 되돌려(`reset --soft`) 둘로 다시 나눴다. 커밋과 다음 쓰기는 `&&`로 잇는다(이미 메모리에 있는 규칙을 이번에 지키지 못했다).
- **worktree에 `server/.env`가 없었다:** 오르카 설정 스크립트는 루트의 `.env`만 복사한다. 시험 서버가 바로 멈췄다. 원래 폴더의 `server/.env`를 복사했다(git에서 빠진 것을 먼저 확인).
