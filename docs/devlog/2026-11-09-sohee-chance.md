## 한 일

- 자유 대화 안에서 라이언은 영어만 쓴다. 「🎤 말하기」 하나로 한국어로 물어도 라이언이 영어로 답한다. 한글이 섞여 받아써진 차례는 한국어로 다시 받아써 「(in Korean)」 표시와 함께 라이언에게 보낸다. PR 1의 정해진 한 줄(「Could you try that in English?」)은 없앴다.
- 대화 안의 정해진 말(못 들었을 때, 녹음이 길 때, Claude가 답하지 못할 때)은 라이언이 영어로 말하고, 화면 글은 한국어 앱 안내로 둔다.
- 라이언 말풍선은 처음에 소리 막대와 「자막 숨김」만 보인다. 다 말하면 「🔊 다시 듣기」, 「자막 보기」, 「통역」이 나온다. 「읽는 법 보기」는 자막을 편 뒤에 나온다.
- 「소희 찬스」: 라이언의 마지막 말에 어떻게 답할지 소희가 대화 안의 말풍선으로 귓속말한다. 1단계는 묻는 뜻 한 줄과 영어 첫마디 두세 개, 2단계 「전체 문장 보기」는 첫마디 하나로 시작하는 짧은 답 문장이다. 소희 목소리는 한국어만, 영어는 글과 라이언 본보기 소리. 대화 돌아보기 위에 「소희 찬스 N번 썼어요」.
- 전체 문장을 본 뒤의 차례는 그 문장과 견준다. 가까우면 평가 없이 이어 가고, 다르게 들린 낱말은 대화 돌아보기에서 내가 만든 말보다 뒤에 맥이 찾은 것으로만 짚는다.
- 라이언은 실수를 지적하지 않고, 서버가 허락한 차례(내 영어 차례 셋에 한 번)에만 맞는 꼴로 자연스럽게 되받는다.
- 대화 돌아보기: 무엇을 묻는 말에 낱말만 한 답은 질문에 맞는 완성 문장으로 고치고, 잘못 받아써진 듯한 낱말은 소리가 가장 가까운 말로 읽고 소리가 다른 말로 메우지 않는다.
- 첫 화면 「자유 대화」 아이콘을 ☕로 바꿨다(🗣️가 갤럭시에서 보라 바탕에 묻혔다).
- 소희 그림 넷을 서버가 내주는 그림 목록과 첫 화면 응답에 더했다. 그림은 저장소에 넣지 않았다.

## 바로잡은 것

- **소희 찬스를 처음에 통역으로 그렸다.** 사용자는 통역 버튼이 이미 있으니 소희 찬스는 답 힌트여야 한다고 했다. 초안을 다시 그렸다.
- **되받기를 지시문의 「가끔」에 맡겼다.** 실수 차례 12번 중 8번을 되받아 너무 잦았다. 서버가 차례를 고르게 하고, 표시가 있으면 8/8 되받는 것을 본 뒤 둘에 한 번에서 셋에 한 번으로 줄였다.
- **새 규칙이 옛 규칙을 흐렸다.** 한국어와 되받기 규칙을 더하자 네 문장 답이 30번 중 2번에서 52번 중 12번으로 늘었다. 길이 규칙을 지시문 끝에 한 번 더 써서 8번으로 줄였다. 규칙을 더하면 옛 규칙도 다시 잰다(가이드 `PROMPT_정해진_말투를_섞기_20261108.md`).
- **라이언이 한글 낱말을 영어 답에 그대로 썼다.** 녹음 시험에서 섞어 물은 한국어 낱말을 「○○ is market」처럼 옮겼다. 영어 목소리로 읽히므로 지시문에 「한글을 쓰지 않는다, 물은 낱말도」를 넣었다.
- **「낱말을 바꿔 말해도 돼요」와 짚는 기준이 어긋났다.** 계획대로라면 바꿔 넣은 낱말도 「~처럼 들렸어요」로 짚었다. 브랜치 최종 리뷰가 찾았고, 소리가 가까운 낱말만 짚게 고쳤다.
- **견주기 스크립트가 서버 패키지를 찾지 못했다.** PR 1의 대화 견주기 스크립트도 문서대로 돌리면 `No module named 'je_server'`였다. 경로를 넣었다.
- **원래 폴더 빌드 실패의 원인:** 원래 폴더의 `app/node_modules`가 잠금 파일보다 오래되어 `react-native-safe-area-context`가 없었다. 할 일로 남겼다(`docs/todo/20261109_01_todo_root_app_npm_ci.md`, 원래 폴더).

- 받아쓰기: 학습자 목소리로 지어낸 한국어 질문 10개를 영어 고정 받아쓰기에 넣어 뜻을 잃은 것 0(한글 7, 같은 뜻 영어 3).

- 실제 모델: 힌트(`compare_hint_models.py`) 걸러진 것 Sonnet 0/16, 전체 문장이 첫마디로 시작 16/16, 가운데 1.53초. 고쳐 주기(`compare_fix_models.py`) 조각 답 완성 6/6, 맞는 문장 바꿈 0, 소리 먼 낱말로 메움 0. 대화 상대(`compare_talk_models.py`) 한국어 섞인 답 0/52, 되받기 표시 있을 때 8/8·없을 때 2/8, 잘못 받아써진 되묻기에 답함 2/2, 네 문장 답 8/52.
- 에뮬레이터(소리 끔, 시험 서버): ☕ 아이콘, 자막 숨김과 자막 보기, 읽는 법, 통역, 소희 찬스 1·2단계(힌트 글 서버 1.8초), 녹음 중에도 소희 말풍선이 보임, 영어 차례 없이 대화 끝내기. 「라이언이 말하는 중」은 소리를 끈 에뮬레이터에서 바로 끝나 보지 못했다.
- API 비용: 약 0.8달러(견주기와 녹음 시험).

## 리뷰

- **작업별 리뷰:** 작업 10개 모두 통과. 고친 것: 전체 문장이 일반 기록 경로로 2단계 전에 앱에 가던 것, 전체 문장의 세 줄 요청이 겹치면 Claude를 두 번 부르던 것, 도움 받은 차례의 설명이 「~라고 말했어요」를 걸러 내지 않던 것, 맞장구 대답까지 완성 문장이 되던 것, 되받기 세기가 라이언 자신의 이야기를 세던 것.
