# 2026-11-07 첫 화면과 복습하기 화면 다시 그리기

- PR: #30
- 문서: PRD 「첫 화면: 라이언이 묻는다」, 「첫 판: 말하기」의 「상황 역할극」과 「복습하기」(전 「다시 연습」). 스펙 `docs/superpowers/specs/2026-11-07-review-screens-design.md`, 계획 `docs/superpowers/plans/2026-11-07-review-screens.md`. ADR은 없다(화면과 이름만 바뀌고 기록과 API는 그대로다).

## 한 일

- 첫 화면 버튼을 설명이 든 카드 둘로 바꿨다. 「대화 연습하기」(파랑, 💬)와 「복습하기」(청록, ↻)다. 라이언은 「오늘은 무엇을 연습해 볼까요?」라고 묻는다.
- 「다시 연습」 메뉴 화면(버튼 둘)을 없앴다. 「복습하기」는 「지난 상황」과 「모아 둔 문장」 두 탭에 바로 목록이 보인다. 앱 상태에서는 메뉴 화면을 지우고 두 목록 화면을 탭으로 그렸다. 그래서 「들어간 탭으로 돌아오기」가 지금의 뒤로 규칙 그대로다.
- 두 목록과 상황 정하기의 목록이 같은 연회색 카드를 쓴다. 지난 상황의 날짜는 「마지막으로 한 날」 하나다. 모아 둔 문장은 ★를 누르면 확인 창에서 묻고 뺀다.
- 화면의 「역할극」을 「대화」로 바꿨다. 코드 이름과 Claude 지시문은 그대로다.
- 안드로이드에서 한국어가 낱말 가운데서 끊기던 것을 고쳤다(`keepWords`).

## 바로잡은 것

- **커밋이 막혔는데 기록이 먼저 적혔다(세 번째):** 커밋 제목이 73자라 막혔는데, 같은 명령에서 `;`로 이은 작업 완료 기록이 빈 범위로 적혔다. 메모리에 「`&&`로 잇는다」가 있는데 `;`를 썼다. 기록을 지우고 제목을 줄여 다시 커밋했다. 이후 커밋과 기록은 모두 `&&`로 이었다.
- **커밋한 계획에 다른 프로젝트 이름을 썼다:** 계획의 에뮬레이터 안내에 이 맥의 다른 프로젝트 AVD 이름과 번호를 적었다. 커밋 전 자동 검사의 금지어 목록에 없어 통과했고, 최종 리뷰가 짚었다. push 전이라 그 커밋을 고쳐(fixup과 autosquash) 기록에서 뺐다. 금지어 목록(비공개)에 다른 프로젝트 이름을 더할지는 사용자가 정한다.
- **보이지 않는 글자를 그대로 썼다:** `keepWords`의 단어 이음 문자를 이스케이프로 쓰려 했는데 파일에는 보이지 않는 글자 그대로 들어갔다. 가이드에서는 확인 방법의 글자가 빈 따옴표로 보였다. 최종 리뷰가 짚었다. 편집기가 그 글자를 지우면 테스트가 통과한 채로 줄바꿈이 다시 깨진다. 이스케이프로 바꾸고 길이를 보는 테스트를 더해, 글자를 빼면 실패하는 것을 봤다.
- **최종 리뷰(브랜치 전체)가 짚은 것 중 다시 매긴 것:** 가이드 색인 누락(`AGENTS.md`가 정한 색인)과 이름 없는 색(스펙 「제약」)은 리뷰어가 Minor로 봤지만 규칙과 스펙을 어긴 것이라 고쳤다. 나머지 작은 넷은 원래 폴더의 todo로 미뤘다.
- **초안에서 줄바꿈을 봤는데 앱에서 다시 겪었다:** 브라우저 초안은 낱말 단위로 줄이 바뀌어 사용자가 짚은 뒤 고쳤지만, 안드로이드는 한글 글자 사이 어디서나 줄을 바꾼다. 스펙에 「폰에서 먼저 보고 고친다」를 적어 두어 에뮬레이터에서 바로 확인하고 고쳤다. 가이드 「한국어가 낱말 가운데서 줄이 바뀐다」에 남겼다.
