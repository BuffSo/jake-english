## 바로잡은 것

- **규칙을 두 번 너무 엄격하게 잡았다.**
  - 사적 복제로 바꾼 뒤에도 「이렇게 구하지 않는다」 목록을 남겼다. 사용자가 PR 요약을 보고 너무 엄격하다고 했다.
  - 원인: 앱과 저장소가 하는 일(공개되는 것)과 사용자가 혼자 하는 일(영상을 구하는 것)을 나누지 않고 둘 다 규칙으로 묶었다.
  - 막는 장치: 가이드 「겪은 문제」에 「규칙은 앱과 저장소가 하는 일에만 두고, 사용자가 혼자 하는 일은 알아 둘 사실로 적는다」를 더했다.
- **혼자 쓰는 앱에 남에게 나눌 때의 기준을 썼다.**
  - 무엇이 문제였나: ADR-0003의 「저작권 걱정이 없는 자료만」을 지키려고 나라마다 공공 저작물인지를 따졌다. 그 결과를 표로 보이고, 고를 것을 네 개 물은 뒤 하나를 더 물었다. 사용자는 너무 복잡하다고 했다.
  - 원인: 혼자 쓰면 사적 복제가 먼저 걸린다. 그 안에서는 공공 저작물인지가 쓸지 말지를 바꾸지 않는다. 그런데 그것을 조사의 첫 질문으로 두지 않았다. main 세션이 넘긴 할 일에는 사적 복제가 4번째로 있었다.
  - 막는 장치: 가이드 「겪은 문제」에 「누가 쓰고, 남과 나누는가」를 먼저 본다고 적었다. 교훈은 비공개 위키 넘김 파일에도 적었다.
- **사용자가 정하지 않은 것을 사용자 결정처럼 쓸 뻔했다.** 넓힐 범위를 사용자는 고르지 않았는데, 처음 쓴 판단에는 그 답 때문에 규칙이 정해진 것처럼 썼다. 리뷰어가 짚었다. AI가 가장 넓게 읽어 정리했다고 고쳤다.
- **리뷰에서 고친 것(고칠 것 5건):**
  - 가이드의 「혼자 쓰는 한 결과가 같다」가 틀렸다. 한국에서 보호되는 영화는 받은 사본이 적법한지가 해석이 갈린다.
  - API 전송의 근거가 ADR-0004의 실제 범위보다 좁았다. 조사는 짧은 문장을 평가에 보내는 경우만 봤는데, ADR-0004는 장면 대본을 팁과 통역에도 보낸다.
  - ADR-0003의 「자료마다 출처를 적어 둔다」가 대체하면서 말없이 사라졌다. 받은 곳을 적는 것은 이어 가기로 했다가, 뒤에 구하는 방법을 사용자에게 맡기며 뺐다.
  - 「His Girl Friday」가 한국에서 자유롭다는 것은 판단인데 사실처럼 썼다. 각본이 따로 보호될 수 있다는 것도 빠뜨렸다.
  - PRD 「하지 않을 것」이 ADR 내용을 옮겨 쓰다가 불법 업로드를 빠뜨렸다. ADR 번호를 가리키게 줄였다.
