# 2026-11-05 집 밖에서 쓰도록 맥과 폰 준비하기

- PR: #11
- 문서: PRD 「첫 판: 말하기」의 집 밖 사용, ADR-0007(Tailscale), ADR-0002(맥에서 빌드), 가이드 `docs/guide/DEVENV_맥을_집밖_서버로_준비하기_20261105.md`. 스펙과 계획은 없다(환경 준비라서).

## 한 일

- main 세션이 역할극 구현(roleplay-mvp)과 환경 준비(이 일)를 두 카드로 나눴다. 이 카드는 저장소의 `app/`, `server/`, 스펙, 계획을 건드리지 않았다.
- 맥에 Tailscale을 깔고, 사용자가 맥과 폰을 같은 계정으로 묶었다. 폰을 모바일 데이터로 두고 맥에 붙는 것을 확인했다.
- 전원에 꽂혀 있을 때 맥이 잠들지 않게 했다. 맥을 다시 켜고 로그인하면 Tailscale이 켜지게 로그인 항목에 넣었다. Standalone 판은 로그인 전에는 돌지 않는다(리뷰에서 짚었다).
- 기존 JDK를 그대로 두고 JDK 17을 옆에 깔았다.
- 개인 값(주소, 기기 이름, 망 이름)은 비공개 메모에 적고 roleplay-mvp 카드에 알렸다. 다른 프로젝트에도 쓸 것은 가이드로 썼다.

## 흐름

## 바로잡은 것

- **확인하기 전에 「다른 패키지는 건드리지 않는다」고 말했다.** homebrew `openjdk@17`을 추천할 때 의존 패키지를 보지 않았다. 사용자가 그 말을 믿고 골랐다. 깔기 전에 `brew deps`와 `brew outdated`를 겹쳐 보고서야 12개가 함께 올라간다는 것을 알았다. 틀렸다고 알리고 다시 고르게 했다. 막는 방법은 가이드에 썼다.
- **화면 조작을 한꺼번에 여러 개 해서 사용자가 따라오지 못했다.** 확장 승인 화면으로 가려고 시스템 설정에 열려 있던 다른 창을 닫았고, Tailscale 앱을 끄려 했고(앱이 거절), 승인 전이라 멈추는 CLI를 불렀다. 사용자가 명령을 멈추고 「뭐가 좀 이상하네, 차근차근 좀 해」라고 했다. 그 뒤로는 한 단계마다 무엇을 할지 말하고, 하고, 결과를 알렸다. 계정 로그인과 암호처럼 사용자가 할 단계는 누르지 않고 넘겼다. 이 방식은 에이전트 메모리에 남겼다.
- **같은 스위치를 여러 번 눌렀다.** 「Start at login」을 접근성 클릭, 좌표 클릭, 창을 앞으로 가져온 클릭으로 세 번 눌렀다. 사용자가 눌러도 켜지지 않는 스위치였다. 두 번 실패하면 멈추고 사용자에게 넘긴다(같은 메모리).

## 검증

- 폰 LTE에서 `http://<맥의 Tailscale 주소>:8765`: 시험 페이지가 떴다. 서버 기록에 폰의 Tailscale 주소로 온 `GET /`가 남았다. 서버를 끈 뒤 포트에 듣는 프로그램이 없었다.
- `systemextensionsctl list`: Tailscale 네트워크 확장 `[activated enabled]`.
- `/usr/libexec/java_home -V`: 25와 17.0.21이 함께 보이고, 기본은 25다. `$(/usr/libexec/java_home -v 17)/bin/java -version`은 17.0.21.
- `pmset -g custom`: AC Power `sleep 0`, Battery Power `sleep 1`.
- 로그인 항목 목록에 Tailscale이 있다.
- 커밋 전 자동 검사 통과.
- 문서 PR이라 pr-review 대신 리뷰어 한 명을 돌렸다. 공개 노출은 없었고, 고칠 것 3건과 사소한 것 몇 건을 고쳤다.
  - Standalone 판은 로그인 전에는 돌지 않는다. 「다시 켜도 켜진다」를 「다시 켜고 로그인하면」으로 고치고 가이드에 한계로 적었다.
  - 「잠자기를 막는 앱이 다시 시작되면 잠든다」는 틀렸다. 「모두 끝나면」으로 고쳤다. 사용자에게도 같은 말을 했는데, 결정(맥 설정으로 정하기)은 바뀌지 않는다.
  - 「JDK 위치」를 비공개 값이라고 했지만 가이드에 표준 위치가 그대로 있었다. 표준 위치라 개인 값이 아니어서 devlog와 PR 본문에서 그 말을 뺐다.
  - homebrew 확인 명령을 `brew install --dry-run`으로 바꿨다. 이 맥에서 「Would upgrade 12 dependencies」가 나오는 것을 확인했다.
