- 카드가 서버를 시험하는 순서를 가이드에 쓰고, `AGENTS.md`에는 가이드를 가리키는 한 줄을 두었다.
- pr-review(리뷰어 6명)에서 나온 것을 고쳤다.

## 바로잡은 것

- **첫 답을 영어로 했다:** 사용자가 「한글로 얘기해」라고 했다. 모든 답을 한국어로 하라는 메모가 이미 있었다. 다시 한국어로 같은 내용을 보냈다.
- **`AGENTS.md`를 말한 것보다 길게 썼다:** 「가리키는 한 줄」로 하겠다고 하고, 명령과 순서를 담은 세 줄짜리 절을 썼다. 같은 순서가 `server/README.md`와 가이드에도 있어 한쪽만 고치면 어긋날 수 있었다. pr-review의 스펙 축이 짚었다. `AGENTS.md`와 `server/README.md`를 가이드를 가리키는 한 줄로 줄이고, 순서는 가이드에만 둔다.
- **`stop` 첫 판이 서버가 다 끝나기 전에 돌아왔다:** 설치한 뒤 실제로 돌려 보니 `launchctl bootout` 바로 뒤에도 옛 whisper-server와 목소리 프로세스가 끝나는 중이었다. 카드가 바로 worktree 서버를 띄우면 받아쓰기 포트에서 부딪칠 수 있다. launchd가 작업을 놓을 때까지 기다리게 고치고, 가짜 `launchctl`로 시험을 더했다. 가이드 「겪은 문제」에 적었다.
- **가이드가 코드보다 많이 약속했다:** 「주소를 잘못 적으면 기다리지 않는다」고 썼는데, 형식이 맞는 틀린 주소는 늦게 뜬 Tailscale과 똑같이 실패해 끝없이 기다렸다. 그러면 `status`는 돈다고 하는데 아무도 포트를 듣지 않는다. pr-review 코드 축이 짚었다(60점). 5분에 오류로 끝내게 고치고, 가이드에 왜 그런지 적었다.
- **확인하지 못한 것을 ADR에 썼다:** 「백그라운드에서 허용」 목록에 「uv」로 보인다고 썼다. `sfltool dumpbtm`으로 확인하려 했으나 관리자 확인을 기다리며 멈춰 껐다. ADR에서 그 이름을 빼고, 비공개 메모에 확인하지 못했다고 적었다.
- **같은 오탐이 두 번째다:** 문서의 `~/Library/Logs/jake-english/server.log`가 PR #15에 이어 다시 「홈 폴더 경로」로 걸렸다(25점, 게시하지 않음). PR #15에서는 코드에 없는 경로라 고쳤고, 이번에는 스크립트가 정한 경로다. `REVIEW.md` 「고치는 방법」대로 「넘길 것」에 그 차이를 적었다.

## 검증

- `cd server && uv run pytest`: 231 passed. 새 시험은 `tests/test_listen.py` 5개, `tests/test_autostart.py` 7개.
- 맥에 없는 주소(`192.0.2.1`)로 띄우면 `waiting to bind JE_HOST:JE_PORT (address not on this Mac yet)`만 남고 whisper-server가 뜨지 않았다.
- worktree에서 `autostart.sh plist`: 원래 폴더의 `server/`를 가리키고 `plutil -lint` OK.
- 설치 뒤: Tailscale 주소 8787에서 `/health`, `/home` 200. `say`로 만든 지어낸 문장을 `/transcribe`로 보내 받아썼다. 목소리 프로세스의 PATH에 homebrew 폴더가 있었다.
- 서버 파이썬을 `kill -KILL`: 4초 뒤 새 서버. `runs = 2`, `last exit code = 137`. 옛 whisper-server와 목소리 프로세스는 남지 않았다.
- `stop`: 0.5초 뒤 돌아오고 8787과 8788이 비었다. 12초 뒤에도 다시 뜨지 않았다. `start`로 다시 떴다.
- `restart`: 새 프로세스로 바뀌었다. 옛 서버는 로그에 `Application shutdown complete.`를 남겼다.
- 아직 하지 않은 것: 로그아웃했다 다시 로그인하기(사용자가 맥 앞에서), 집 밖에서 폰으로 붙기, 머지 뒤 `restart`, 재시동.
