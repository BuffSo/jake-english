## 바로잡은 것

- 기록 검사 스크립트가 작업 폴더를 저장소로 옮긴 뒤 결과 파일을 상대 경로로 써서, 결과 파일이 worktree 맨 위에 생겼다. 커밋 전에 보고 scratchpad로 옮겼다. 결과 파일에는 찾은 줄이 그대로 들어 있어, 커밋되면 그것이 새 노출이 된다. 검사 스크립트의 출력 경로는 절대 경로로 쓴다.
- GitHub의 PR 참조(`refs/pull/*/head`)를 검사하려고 로컬 참조로 받아 왔다. 다른 worktree의 `git branch -a`에도 보이므로 검사가 끝난 뒤 지웠다.
