## 바로잡은 것

- **리뷰 뒤 수정 범위를 사용자에게 물었다.** pr-review 스킬은 코멘트를 게시한 뒤 어디까지 고칠지 묻는다. 이 저장소 규칙(`AGENTS.md` 「PR과 머지」, `CLAUDE.md` 「PR 리뷰」)은 확인된 문제를 묻지 않고 고친다. 저장소 규칙이 스킬보다 앞서는데 스킬을 그대로 따랐다. PR #1에서도 같았다. 사용자가 짚었다.
  - 더한 장치: `CLAUDE.md` 「PR 리뷰」에 「수정 범위를 묻는 단계는 이 저장소에서 건너뛴다」를 넣었다(PR #3). 스킬은 다른 저장소도 쓰므로 고치지 않았다.
- **가이드를 쓰고 나서야 push 전 검사의 버그가 드러났다.** 검사를 만들 때의 시험 파일 이름이 모두 영어였다. 가이드에 「시험의 파일 이름에 ASCII 밖의 글자를 하나 이상 넣는다」를 적었다.
- **`REVIEW.md` 「고치는 방법」 점검:** 코드 축은 지적이 없어 「넘길 것」에 넣을 오탐이 없다. 이번 버그는 리뷰가 놓친 것이 아니라 시험이 비어 있던 것이라, 「반드시 지적할 것」이 아니라 시험과 가이드로 옮겼다.
