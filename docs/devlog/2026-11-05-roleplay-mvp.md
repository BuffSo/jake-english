## 바로잡은 것

- **커밋 하나가 실패한 뒤 다음 커밋에 파일이 섞였다:** 첫 커밋이 제목 길이로 막혔는데, 줄을 바꿔 쓴 다음 `git add`와 `commit`이 그대로 돌았다. 스테이징에 남은 서버 파일이 ADR 커밋에 들어갔다. push 전이라 `reset --soft`로 풀고 셋으로 다시 커밋했다. 그 뒤로는 `add`와 `commit`을 `&&`로 이었다.
- **잠금 파일 고치기와 커밋을 한 명령에 묶었다:** 커밋 가드 훅은 명령을 실행하기 전의 스테이징을 본다(`CLAUDE.md`에 이미 적혀 있다). 그래서 고치기 전 상태로 막혔다. 나눠 실행했다.
- **Gradle이 멈춘 줄 알고 두 번 끊었다:** CMake 단계에서 조용했는데 사실은 react-android(171MB)를 느린 연결로 받는 중이었다. 병렬 빌드를 의심해 `--no-parallel`로 한 번 헛돌렸다. 스레드 덤프로 확인하는 법을 가이드에 남겼다(`docs/guide/APP_Expo_앱_뼈대와_서버_연결_20261105.md`).
- **시험이 구현보다 늦은 곳:** `Claude.feedback`, `offscript`, `continue_script`의 직접 시험은 구현 뒤에 썼다. 코드를 일부러 바꿔 시험이 실패하는지 보고 되돌렸다.
- **가짜가 진짜를 가린 시험:** 다르게 말하기가 겹치는 문제의 첫 시험은 고치기 전에도 통과했다. 가짜 Claude가 대화 기록을 보지 않았기 때문이다. 기록을 남기게 고쳐 실패를 확인했다.
- **리뷰가 찾은 것(최종 리뷰 4건, pr-review 7건과 스펙 1건):**
  - 주머니 속 톡 소리 한 번이 말소리로 판정됐다.
  - Claude의 400, 401 같은 실패가 「맥에 연결할 수 없어요」로 보였다.
  - 다시 해 보기 뒤 라이언의 대답이 대화에서 사라졌다.
  - 토큰 확인 전에 본문을 읽었다.
  - 60초 자동 멈춤이 서버 한도를 넘었다.
  - 두 번 누르기, 화면을 떠난 뒤의 늦은 오류, 빠르기 파일 동시 생성, 다르게 말하기 겹침, 다시 만든 대본의 줄 수가 문제였다.
  - 모두 시험을 먼저 쓰고 고쳤다. 작은 문제 4건은 `docs/todo/20261105_11_todo_roleplay_mvp_review_minors.md`에 남겼다.
- `REVIEW.md`는 고치지 않았다. 되풀이된 오탐이 없었고, 리뷰가 놓친 문제가 나중에 드러난 것도 없었다. 「크기 제한 없이 받는 업로드」 항목이 토큰 확인 전 본문 읽기를 잡아냈다.
