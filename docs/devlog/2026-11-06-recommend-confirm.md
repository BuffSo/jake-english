## 바로잡은 것

- **새 버튼의 두 번 누르기를 먼저 보지 않았다:** 「이걸로 할게요」를 빠르게 두 번 누르면 대본이 두 번 만들어졌다. 「다른 걸로요」도 추천을 두 번 받았다. PR #12(녹음 두 번 올리기)와 PR #15(복사 두 번)에 이어 세 번째다. 이전 PR 코멘트를 보는 리뷰어가 잡았다.
  - 리뷰가 제안한 `createGate`는 쓰지 않았다. 게이트는 일이 끝날 때까지 닫혀 있는데, 대본 만들기는 제이크 말까지 기다려 오래 걸린다. 그 사이 「뒤로」를 누르면 같은 게이트를 쓰는 마이크가 막힌다. 그래서 질문 하나에 답 하나만 받는 `createLatch`를 더했다.
  - 가이드 APP에 「버튼을 두 번 누르면 같은 요청이 두 번 간다」를 쓰고, 게이트와 래치를 언제 쓰는지 적었다.
- **바뀐 흐름을 다른 가이드가 옛날대로 적고 있었다:** 스펙과 PRD는 고쳤지만, 가이드 APP의 「고친 것」에 「대본은 제이크가 말하는 동안 같이 만든다」가 남아 있었다. 스펙 대조 리뷰어가 찾았다. 흐름을 바꿀 때는 그 흐름을 적은 가이드도 찾아본다.
- **`REVIEW.md`는 고치지 않았다:** 되풀이된 오탐이 없었다. 두 번 누르기는 되풀이된 실수지만 리뷰가 놓치지 않았다. 그래서 「반드시 지적할 것」에 넣지 않고, 만들 때 막도록 가이드에 썼다.
