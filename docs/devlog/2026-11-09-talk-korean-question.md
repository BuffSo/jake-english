## 한 일

- 자유 대화의 「🎤 말하기」를 영어로 받아쓸 때, 받아쓰기 서버가 함께 주는 한국어일 확률도 받는다(`Whisper.transcribe_english`).
- 한글이 섞였거나 한국어일 확률이 0.98 이상이면 한국어로 다시 받아써 한국어 차례로 다룬다(`Talks._hear`). 한국어 차례는 지금처럼 내 말풍선에 한국어로 보이고, 라이언에게 「(in Korean)」과 함께 가고, 대화 뒤 고쳐 주기에서 빠진다.
- 확률로만 한국어라 했는데 다시 받아쓴 글에 한글이 없거나 받아쓰기가 실패하면 영어 차례로 둔다.
- 차례마다 한국어일 확률 숫자를 서버 로그에 남긴다(`korean_p=`). 받아쓴 글은 남기지 않는다.
- 앱은 바꾸지 않았다. 서버가 보내는 `korean`과 글을 이미 쓴다.

## 바로잡은 것

- **쉬운 낱말로만 잰 시험이 문제를 가렸다.** PR 2는 지어낸 한국어 질문 10개로 뜻을 잃은 것이 0개라며 버튼 없이 갔다. 이번에 관용 표현, 신조어, 줄임말을 묻는 질문 20개로 다시 재자 6개가 뜻을 잃었다. 가이드 「영어로 옮겨진 한국어 질문의 뜻이 바뀐 문제」의 「막는 법」에 시험 문장 고르는 기준과 실제 녹음으로 함께 세는 법을 적었다.
- **지어낸 목소리와 실제 목소리가 다르게 받아써졌다.** 영어로 옮겨진 것이 지어낸 목소리는 20개 중 13개, 실제 목소리는 8개 중 7개였다. 지어낸 목소리만 보고 정하지 않으려고 실제 녹음은 읽기만 하고, 글은 터미널에서만 보고, 개수와 확률만 적었다.
- **재는 스크립트가 같은 이름의 WAV를 덮어썼다.** 실제 녹음의 사본 이름을 `줄-번호.wav`로 지어, 역할극이 달라도 이름이 같은 사본이 서로 덮어썼다. 재는 값은 녹음마다 바로 받아써서 맞았지만, 나중에 다시 들으려던 사본은 다른 녹음이었다. 원본에서 다시 만들어 확인했다. 재는 스크립트는 저장소 밖 임시 폴더의 것이라 고치지 않았다.
- **커밋이 막힌 뒤 원장 줄이 이어 돌았다.** 작업 2의 첫 커밋이 제목 길이(75자)로 막혔는데, 그 뒤의 원장 기록 명령을 `&&`가 아닌 줄바꿈으로 이어 「완료」가 잘못 적혔다. 잘못 적힌 줄을 지우고 다시 커밋한 뒤 다시 적었다. 커밋 뒤에 잇는 명령은 `&&`로 잇는다(이미 있는 규칙).

- **시험 서버를 끄다 원래 폴더 서버까지 껐다.** 정리할 때 `pkill -f je_server`로 시험 서버를 껐는데, 같은 명령 줄인 원래 폴더 서버도 꺼졌다. launchd가 4초쯤 뒤 다시 띄웠고, 꺼지기 전 7분 동안 요청은 없었다. 가이드 `DEVENV_맥서버_저절로_띄우기_20261107.md`에 「시험 서버를 이름으로 끄다 원래 폴더 서버까지 껐다」를 더했다. 시험 서버는 포트로 찾아 끈다.
