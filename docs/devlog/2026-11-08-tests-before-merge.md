## 흐름

| 정할 것 | AI 추천 | 사용자 판단 | 결과 |
|---|---|---|---|
| 폰 확인을 누가 하나 | (전에는) PR 체크리스트에 `[ ]`로 남겨 사용자가 폰에서 본다 | 「테스트까지 마친 다음에 내가 머지만 하라고 하게」 | 에이전트가 adb로 직접 본다. 체크리스트에 빈 칸을 두지 않는다 |
| 끝내 못 한 시험을 어디 적나 | 빈 칸 대신 `## 한계`에 이유와 함께 | (AI 판단) | 그렇게 썼다 |
| adb 다루는 법을 어디 두나 | 앱 가이드 여기저기에 흩어져 있어 DEVENV 가이드로 따로 | (AI 판단, 할 일 파일이 「없으면 가이드에」라고 정함) | 새 가이드 |

## 바로잡은 것

- 사용자가 새 규칙을 말한 뒤에도 `AGENTS.md`가 옛 규칙(빈 칸으로 남기기)이었다. main 세션은 카드마다 넘길 글로 전하고 Claude Code 메모리에 적었지만, 다른 에이전트와 새 세션은 `AGENTS.md`만 읽는다(같이 도는 카드가 짚었다). 규칙은 말로 전하는 것으로 끝내지 않고 규칙 문서에 넣는다.
