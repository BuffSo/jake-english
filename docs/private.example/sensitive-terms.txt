# 쓰는 법
# - 한 줄에 낱말 하나. 대소문자를 가리지 않고, 줄 속에 들어 있기만 해도 걸린다.
# - re: 로 시작하는 줄은 정규식이다(대소문자를 가린다). 잘못 쓴 정규식은 검사를 멈춘다.
# - # 으로 시작하는 줄은 주석이라 검사하지 않는다. 빈 줄도 건너뛴다.
# - 이 파일이 없으면 커밋이 막힌다. 막을 낱말이 아직 없어도 파일은 둔다.
#
# 예(주석이라 검사하지 않는다. 이 저장소에 맞는 낱말로 바꿔 # 없이 쓴다):
# my-secret-codename
# re:\bproject-x-\d+\b
