# 비공개 메모 (git에 넣지 않음)

이 폴더(`docs/private/`)는 `.gitignore`로 git에서 뺐다. 공개하면 안 되는 것은 여기에만 쓴다. 에이전트는 일을 시작할 때 이 파일을 먼저 읽는다(`AGENTS.md` 「먼저 읽을 것」).

이 파일은 `docs/private.example/`의 빈 양식을 복사한 것이다. 각 절의 설명 줄을 지우고 이 저장소의 내용으로 채운다.

## 여기 있는 파일

이 폴더에 둔 파일과 각각 무엇인지 한 줄씩 적는다.

- `sensitive-terms.txt`: 커밋 전 자동 검사가 읽는 비공개 금지어 목록. 목록 자체가 민감 정보라 여기에 둔다.

## 공개 파일에 쓰지 않는 것

커밋하는 파일, 커밋 메시지, PR 본문에 쓰면 안 되는 것을 적는다. 예: API 키와 토큰, 홈 폴더 같은 개인 경로, 집이나 회사의 내부 주소.

공개 파일에는 「비공개 메모 참고」라고만 쓴다. 낱말로 막을 수 있는 것은 `sensitive-terms.txt`에도 넣는다.
