## 왜 하나

2026-11-09 main 세션이 PR #67, #68 머지 뒤 폰에서 자유 대화를 시험하고, 시험으로 생긴 대화 기록(폰 마이크로 들어간 녹음 포함)과 학습자 목소리로 만든 녹음을 묻지 않고 바로 지웠다. 그 뒤 사용자가 시험에서 라이언의 한 낱말이 다르게 들렸다고 했다. 무엇이 어떻게 들렸는지 다시 들어 볼 소리 일부가 이미 지워져 있었다.

사용자(그대로): 「다음부턴 테스트 한녹음 파일은 나한테 먼저 물어 삭제해도 되겠냐고....」, 이어서 「내가 가끔 모니터링하면 거기에 대해 코멘트 할수도 있으니까 .. 코멘트 없이 지나가면 그때 지우는 방식으로」, 다시 「에뮬레이터에서 테스트 한 음성 파일들은 바로지워도 돼.. 내가 얘기한건 폰에서 테스트할때의 녹음파일을 말한거야」

## 할 일

1. `AGENTS.md` 「시험은 에이전트가 다 마친다」 쪽에 한 줄 더한다: **폰에서** 시험해 생긴 녹음 파일(폰 마이크로 들어간 녹음, 폰에 틀어 넣은 학습자 목소리 녹음, 그 녹음이 든 시험 대화 기록)은 바로 지우지 않는다. 에뮬레이터 시험과 폰 없이 서버에 바로 보낸 시험의 녹음은 지금처럼 끝나면 바로 지운다. 시험 결과를 알릴 때 「지울 시험 녹음: 어디에 무엇이 몇 개」를 함께 적고, 사용자가 그에 대해 코멘트 없이 다음으로 넘어가면 그때 지운다. 따로 「지워도 될까요?」라고 답을 기다리는 질문은 하지 않는다. 카드는 main 세션을 거쳐 알린다. 이유와 사용자의 말을 함께 적는다.
2. 「끝나면 지운다」고 적힌 가이드를 같은 규칙으로 고친다.
   - `docs/guide/DEVENV_폰없이_녹음_시험하기_20261108.md` 4
   - `docs/guide/DEVENV_폰을_adb로_시험하기_20261108.md` 13줄 「사용자 기록에 시험을 섞지 않는다」와 「겪은 것」의 마이크 녹음을 바로 지운 줄
   - `docs/guide/DEVENV_맥서버_저절로_띄우기_20261107.md` 「카드가 서버를 시험할 때」의 데이터 사본
3. 묻는 동안 지우지 않은 시험 기록이 사용자의 실제 기록에 섞여 보이지 않게 하는 방법도 적는다. 예: 시험 서버의 데이터 사본에만 두기, 실제 서버로 시험했으면 시험 대화 폴더를 임시 폴더로 옮겨 두고 묻기.
4. 규칙 문서라 PR로 올린다(`AGENTS.md` 「작은 문서 커밋」).
