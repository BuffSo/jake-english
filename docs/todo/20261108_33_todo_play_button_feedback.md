# TODO: 듣기 버튼을 누르면 바로 소리 나는 중인 것을 보이고, 늦게 나오지 않게

> 작성: 2026-11-08
> 상태: **완료** (2026-11-08 record-feedback 카드, `feat/play-button-feedback`, 스펙 `docs/superpowers/specs/2026-11-08-play-button-feedback-design.md`. 녹음은 폰에 두지 않고 맥이 앞뒤 침묵을 잘라 낸 사본을 내주기로 사용자가 정했다)

## 왜 하나

2026-11-08 사용자가 폰에서 「🔊 내 녹음」을 눌렀는데 아무 반응이 없다가 늦게 녹음 소리가 들렸다. 사용자: 「내 녹음 누르면 플레이되고 있다는 표시가 나와야 할 듯」.

main 세션은 처음에 누르면 「불러오는 중…」, 소리가 나는 동안 「■ 멈추기」로 글자를 바꾸자고 추천했다. 사용자는 「UI가 너무 복잡하게 변화하는 것 같다」며 이렇게 정했다: 「내 녹음 표시는 그대로 하고, 이게 스피커 꽝꽝 울리는 것처럼 표현해 주면 더 좋을 것 같은데, 나머지는 이에 맞게 알아서」.

## 할 일

1. **글자는 그대로, 스피커가 울리는 것처럼:** 「🔊 내 녹음」의 글자는 바꾸지 않는다. 누르는 순간부터(받아 오는 동안 포함) 소리가 끝날 때까지 스피커 표시가 울리는 것처럼 움직인다(예: 소리 물결이 퍼지는 움직임). 끝나면 멈춘다. 모양은 초안을 만들어 main 세션에 보내 사용자가 보고 정한다.
2. **나머지는 카드가 정한다(사용자가 맡김):** 울리는 동안 다시 누르면 멈출지, 다른 듣기 버튼을 누르면 앞의 소리를 멈출지 같은 것.
3. **늦게 나오지 않게:** 지금은 누를 때마다 맥에서 녹음을 받아 와 늦다(원인은 재서 확인한다). 방금 녹음한 것은 폰에 남은 파일을 바로 틀고, 맥에서 받아 온 것은 다음에 바로 틀 수 있게 폰에 잠시 둔다. 녹음 취소와 보관 규칙(record-cancel-skip 스펙, ADR의 녹음 보관)과 어긋나지 않게 한다.
4. **다른 듣기 버튼도 같게:** 「🔊 다시 듣기」, 「🔊 처음 녹음」, 통역, 「눌러서 듣기」처럼 소리를 트는 버튼을 같은 방식으로 맞춘다.
