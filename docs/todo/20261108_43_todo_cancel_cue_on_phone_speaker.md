# TODO: 취소 소리가 폰 스피커에서 시작 소리보다 11 dB 작다

> 작성: 2026-11-08 (noisy-room 카드, PR #60 폰 시험 중)
> 상태: **완료** (2026-11-08 small-sweep-3 카드)

## 본 것

- PR #59가 알림 소리 진폭을 반으로 낮췄다. 폰 스피커로 나온 소리를 맥 마이크로 쟀다(0.4초 크기, ebur128 momentary, 숫자만 기록하고 소리는 남기지 않음).
  - 라이언 대사(「다시 듣기」): 최대 -39 LUFS, 대개 -40~-46.
  - 시작 소리(659→880Hz): 세 번 모두 -43.
  - 취소 소리(392Hz 한 음): 세 번 모두 -54. 방 소리는 -61~-66이었다.
- 시작 소리는 라이언보다 조금 작아 스펙대로다. 취소 소리는 시작 소리보다 11 dB 작아, 시끄러운 곳에서 못 들을 수 있다. 낮은 음(392Hz)이 폰 스피커에서 약한 것으로 보인다. 코드의 진폭 차이(0.25 대 0.225)는 1 dB뿐이다.

## 할 것

1. 취소 소리의 음을 폰 스피커가 잘 내는 높이로 올리거나(예: 523Hz), 두 음으로 만들어 「내려가는 끝 소리」와 헷갈리지 않게 한다. 진폭을 키우는 것만으로는 낮은 음이 잘 들리지 않을 수 있다.
   - (2026-11-08 함) 사용자가 초안을 듣고 「같은 392Hz 한 음에 2배음과 3배음을 섞은 소리」를 골랐다(523Hz 한 음도 후보였다). 진폭은 0.5.
2. 바꾼 뒤 같은 방법으로 폰 스피커에서 재어 시작 소리와 3 dB 안쪽인지 본다. 재는 방법은 `docs/guide/APP_녹음_중_알리기_20261108.md`에 더한다.
   - (2026-11-08 함) 네 번 재어 시작 -43.5~-44.0, 취소 -45.6~-46.9 LUFS. 평균 2.4 dB 차이(한 번은 3.3). 재는 방법은 가이드 「알림 소리가 폰 스피커에서 얼마나 크게 나는지 재기」.
