# TODO: 녹음하는 동안 「취소」 버튼

> 작성: 2026-11-08
> 상태: **완료** (2026-11-08 PR #45, 스펙 `docs/superpowers/specs/2026-11-08-record-cancel-skip-design.md`)

## 왜 하나

2026-11-08 offscript-aside 폰 시험 중에 사용자가 말했다. 「말하기 하면 지금은 무조건 저장해야 하는거잖아? 여기에 저장 취소할 수 있는 버튼이 있어야 할것 같아..」

지금은 「🎤 말하기」로 녹음을 시작하면 「■ 말하기 끝」을 눌러야만 멈추고, 누르면 바로 맥으로 보내져 평가를 받는다. 말이 꼬였을 때 보내지 않고 버릴 방법이 없다.

PR #29는 보낸 뒤에 선생님 라이언이 알맞게 답하게 했다. 취소는 보내기 전에 버리는 것이라 둘 다 쓸모가 있다. 취소하면 라이언의 답을 기다리지 않고 Claude도 부르지 않는다.

## 할 일 (AI 추천을 사용자가 받아들임)

1. 녹음하는 동안 「■ 말하기 끝」 옆에 「취소」 버튼을 둔다.
2. 누르면 녹음을 버리고 말하기 전 화면(`ready`)으로 돌아간다. 맥에 보내지 않으니 기록에 남지 않고, 폰에도 녹음 파일을 남기지 않는다(`useRecorder`의 `discard`, 뒤로가기가 이미 하는 일).
3. 화면 모양(버튼 자리, 이름)은 스펙에서 정한다. 역할극 화면과 복습 화면 모두 같은 녹음 버튼을 쓴다(`app/src/screens/RoleplayScreen.tsx`).
4. 녹음 시작과 멈춤이 겹치지 않게 하는 게이트(`createGate`, `stopThenSend`)와 함께 시험한다. 「말하기 끝」과 「취소」를 빠르게 같이 누르는 경우도 본다.

## 더한 것: 녹음 없이 다음 대사로 넘어가기 (2026-11-08, main 세션)

- 사용자가 폰으로 역할극을 하다 앱에 한국어로, 녹음하지 않고 다음 대사로 갈 길이 있으면 좋겠다는 바람을 말했다. main 세션에서 「웅 맞아」라고 실제로 바라는 기능임을 확인했다. 그 말을 받아쓴 글은 공개 파일에 옮기지 않는다.
- 지금은 내 차례에서 녹음을 보내고 따라 말했다고 평가돼야 다음 대사로 간다. 녹음을 건너뛸 길이 없다.
- 「취소」(녹음을 버리고 말하기 전으로)와 같은 버튼 자리라 함께 스펙을 쓴다. 정할 것: 버튼 이름(예: 「건너뛰기」), 녹음하기 전에도 보일지, 건너뛴 대사를 끝 화면과 「지난 상황」에 어떻게 남길지(시도 없음), 라이언이 다음 대사를 이어 말하는지.
- 하지 않을 것: 점수, 연속 기록처럼 건너뛰기를 벌하는 표시는 두지 않는다(PRD 「하지 않을 것」).
