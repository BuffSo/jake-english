## 지금 모양 (2026-11-08 코드로 확인)

- 통역 글은 「통역」을 처음 누를 때 짧은 말 모델(`server/.env`의 `JE_CLAUDE_QUICK`, 지금 Haiku)로 만들고 그 줄에 저장한다(`Engine.ko`, `Claude.interpret`). 소희 소리도 처음 누를 때 맥에서 만들어 저장한다(`Engine.ko_audio`).
- 같은 대본을 다시 하면(목록 상황의 다음 회차, 「이 상황 다시 하기」) 앞 회차의 통역 글과 소리를 그대로 쓴다(`Engine._prepared`). 같은 줄로는 처음 한 번만 Claude를 부른다.
- 목록 상황의 대본은 저장소의 `server/je_server/topics.py`에 영어 줄로 써 있다(PR #34, ADR-0013). 통역은 없다.
- 소희 통역 스펙(`docs/superpowers/specs/2026-11-06-korean-translation-design.md`)은 「미리 만들지 않는다(AI 판단)」이다. 누르지 않는 줄이 많을 것이라는 이유였다. 목록 대본은 회차마다 다시 쓰므로 이유가 달라진다.
- 잰 값(그 스펙 「잰 것」): 통역 글 1초 안팎, 한 번에 0.01센트가 안 됨(Haiku). 소희 소리는 한 문장 7초쯤으로, 처음 누를 때의 기다림은 대부분 소리다.
- 제이크 추천, 라이언의 평가, 소희 통역이 같은 짧은 말 모델 설정을 쓴다. 통역만 바꾸려면 코드를 고쳐야 한다.

## 할 일 (main 세션 추천, 사용자가 받아들임)

1. **통역 모델 견주기:** 대사 열 줄쯤을 Haiku와 Sonnet으로 각각 통역해 나란히 보여 주고, 사용자가 읽어 보고 정한다. 대사는 저장소의 목록 대본이나 지어낸 것을 쓴다(사용자의 지난 기록 문장은 쓰지 않는다). 비용은 2센트 안쪽이고, 시작할 때 한 줄로 알린다.
   - Sonnet은 값이 스무 배라 한 번에 0.2센트쯤, 역할극 하나의 모든 줄을 통역해도 1센트 안팎이다. 글이 1~2초 늦어질 수 있지만 소리 7초가 더 길다.
   - 사용자가 Sonnet을 고르면 통역만 글쓰기 모델로 바꾼다. 스펙과, 모델 설정을 다룬 곳(말하기 스펙 「기다리는 시간과 모델」, ADR-0004 「영향」)을 함께 고친다.
2. **목록 대본에 통역 써 두기:** `topics.py`의 목록 대본 줄마다 소희의 한국어를 써 둔다. 1에서 고른 모델로 한 번 만들고, 사람이 읽어 고친 것을 저장소에 둔다. 공개 파일이라 「공개 저장소」 규칙을 지킨다. 목록에서 고르면 그 한국어가 처음부터 그 줄의 통역이 되어 Claude를 부르지 않는다.
3. **소희 소리 미리 만들기:** 목록 상황을 처음 고를 때, 라이언의 본보기 소리처럼 소희 소리도 뒤에서 만들어 둔다. 라이언 본보기와 내 대사 준비가 먼저이고, 소희 소리는 그 뒤에 만든다(첫 대사가 늦어지지 않게). 맥에서 만들어 돈은 들지 않는다. 한 번 만들면 다음 회차부터 그대로 쓴다.
4. 소희 통역 스펙의 「미리 만들기」와 목록 대본 스펙(`docs/superpowers/specs/2026-11-08-fixed-list-scripts-design.md`), 필요하면 ADR-0013 「영향」을 고친다.

## 어떻게 끝났나 (2026-11-08)

1. **모델:** 목록 대본 열 줄을 Haiku와 Sonnet으로 통역해 표로 보였다. 뜻은 둘 다 맞았고 Sonnet이 네 줄쯤 더 자연스러웠다. AI가 Haiku를 그대로 두자고 추천했고(목록 대본은 사람이 고쳐 두니 차이는 실시간 통역에만 남고, Sonnet은 스무 배 비싸다), 사용자가 「일단 추천으로 하자」고 했다. 모델 설정은 바꾸지 않았다. 견준 비용은 Haiku 0.1센트, Sonnet 2.1센트.
2. **통역 써 두기:** `server/je_server/topics.py`의 대본 줄마다 소희 한국어를 영어 옆에 썼다(39줄). Haiku로 만들고 33줄을 고쳤다(0.3센트). 사실 시험과 「현금은 충전기에만」 시험을 더했다. 사용자의 지난 기록과 문장 단위로 맞대어 줄 전체가 같은 것 0, 6자 이하 인사말 다섯만 같았다.
3. **소희 소리 미리 만들기:** 목록 상황을 고르면 그 역할극의 본보기 소리와 읽는 법 뒤에 뒤에서 만든다(`Engine._sohee_later`). 한 번에 하나씩, 녹음에 답하는 동안은 새로 시작하지 않는다. 처음 고른 운동화 사이즈의 첫 내 대사는 0.04초였다(PR #36의 0.03초와 같다).
4. **문서:** 소희 통역 스펙(「하지 않을 것」의 미리 만들기, 「제약」, 「잰 것」), 목록 대본 스펙, 말하기 스펙 「기다리는 시간과 모델」, ADR-0013 「영향」, PRD 「통역」을 고쳤다. 새 ADR은 쓰지 않았다(ADR-0013을 넓힌 것).
