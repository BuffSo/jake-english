## 왜 하나

2026-11-08 사용자가 폰으로 연습하다 몇 번 같은 실수를 했다. 녹음 중이라고 생각하고 말한 뒤 「말하기 끝」을 눌렀는데, 사실은 녹음이 켜져 있지 않아 그때 누른 것이 「🎤 말하기」였다. 누르고 나서야 알아채 얼른 다시 말했다.

- 「🎤 말하기」와 「■ 말하기 끝」은 같은 자리에서 글자만 바뀐다. 말에 집중하면 버튼을 보지 않는다.
- 자유 대화(`20261105_09_todo_speaking_practice_next.md`)도 말의 시작과 끝을 버튼으로 하기로 해서(사용자 결정) 같은 문제가 생긴다.
- 사용자는 「말하기를 누르고 한참 동안 말을 안 하면 자동으로 녹음이 종료 또는 취소되어야 하지 않나」라고 물었다. 지금은 55초(`app/src/config.ts`의 `RECORD_LIMIT_MS`)가 지나면 저절로 멈춰 맥에 보내고, 맥은 말소리가 없으면(`server/je_server/audio.py`의 `has_speech`) 그에 맞게 답한다. 그동안 사용자는 녹음 중인 줄 모를 수 있다.

## 할 일 (main 세션 추천을 사용자가 「ㅇㅋ」로 받아들임)

1. **녹음이 켜지고 꺼질 때 짧은 소리와 진동:** 화면을 보지 않아도 시작과 끝을 안다. 시작과 끝은 다른 소리로 한다. 「취소」도 따로 알 수 있게 한다.
2. **녹음 중 표시 (2026-11-08 초안을 보고 사용자가 정함):** 「● 말하기 끝」(파란 버튼, 빨간 동그라미가 천천히 깜빡임)과 버튼 아래 얇은 하늘색 목소리 줄. 50초부터 「녹음이 곧 끝나요」. 처음 추천한 빨간 띠와 흐르는 초는 사용자가 「너무 강렬하다, 너무 튄다」고 해 뺐고, 동그라미와 네모(■)를 함께 두는 것도 「별로」라 동그라미 하나만 남겼다.
3. **라이언 말이 끝나면 한 줄 안내:** 「🎤를 누르고 말하세요」를 잠깐 보인다. 매번 보여 화면이 시끄럽지 않게, 언제 보일지는 스펙에서 정한다.
4. **말이 없으면 녹음 취소, 말하다 오래 쉬면 저절로 끝 (2026-11-08 사용자 결정):** 「🎤 말하기」를 누른 뒤 말소리가 한 번도 없이 5초가 지나면 녹음을 버리고 말하기 전으로 돌아간다(맥에 보내지 않음, 취소 소리). main 세션은 8초를 추천했으나 사용자가 「5초만 해도 될 것 같은데」라고 정했다. 말하다가 8초 동안 말이 없으면 저절로 「말하기 끝」으로 처리해 보낸다(사용자가 5초를 말했고, 보내는 것이라 main 세션이 8초를 추천해 받아들임). 55초 상한은 그대로 둔다. 말소리를 무엇으로 볼지는 폰에서 재 보고 정한다.
5. 역할극, 역할극 뒤 연습, 복습, 대화 중 한 줄 연습 모두 같은 녹음 버튼이라 함께 바뀐다.
