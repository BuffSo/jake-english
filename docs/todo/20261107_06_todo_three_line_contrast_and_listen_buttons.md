## 더한 것 (2026-11-08, main 세션)

### 5. 대화 중에 방금 녹음한 내 말 듣기

- 사용자의 물음: 「상황에 따른 대화를 할 때 말하기 누르고 녹음 누르잖아. 방금 녹음한 내 말을 듣는 방법은 없나?」
- 지금(2026-11-08 코드로 확인): 녹음은 맥에 저장되고, 끝 화면의 「주고받은 말」에서 내 대사를 펼치면 시도마다 「▶ 내 녹음」이 나온다(`EndScreen.tsx`의 `TryView`, `api.recordingSource`, 서버 `GET /roleplays/{id}/lines/{idx}/attempts/{n}/recording`). 역할극 화면(`RoleplayScreen.tsx`)에는 녹음을 트는 버튼이 없다.
- main 세션 추천(사용자가 이어서 버튼 모양을 말해, 더하는 것으로 받음):
  - 녹음을 보내고 라이언의 평가가 나온 상자에 「내 녹음」을 둔다. 본보기를 듣는 「다시 듣기」 옆이라 둘을 견줘 듣기 쉽다.
  - 대화 기록의 지나간 내 말풍선을 펼쳤을 때도 둔다(3의 「듣기」와 같은 버튼 줄, 끝 화면과 같은 모양).
  - 녹음하는 동안과 라이언이 말하는 동안에는 막는다.

### 6. 듣기 버튼의 표시를 ▶ 대신 소리 표시로

- 사용자의 말: 「▶ 이것도 좀 바꾸지. 들려주는 거면, 이걸 누르면 말한 목소리 또는 말할 목소리가 들린다는 의미로.」
- 지금 ▶가 붙은 곳(2026-11-08): 끝 화면의 「▶ 듣기」, 「▶ 처음 녹음」, 「▶ 내 녹음」, 통역 줄 끝의 「▶」(`app/src/ui/Interpret.tsx`). 본보기의 「다시 듣기」는 표시 없이 글만 있다. 말하기는 「🎤 말하기」처럼 그림 글자를 쓴다.
- main 세션 추천(사용자 판단 전): 소리를 트는 버튼은 모두 「🔊」로 맞춘다. 예: 「🔊 듣기」, 「🔊 내 녹음」, 「🔊 처음 녹음」, 「🔊 다시 듣기」. 이미 쓰는 「🎤」와 같은 그림 글자라 새로 설치할 것이 없다. 아이콘 묶음(벡터 아이콘)을 쓰려면 새 의존성이라 먼저 묻는다.
- 화면 초안(4)에 이 표시를 넣어 함께 고르게 한다. 버튼 색 검토(`20261107_11_todo_button_color_review.md`)와 모양을 맞춘다.
