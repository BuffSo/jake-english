## 왜 하나

review-practice(PR #27)를 폰에서 확인하며 사용자가 말했다.

- 「목록 화면이 안 이쁘네」(지난 상황 목록을 보고)
- 「다시 연습이라고 하고 버튼 2개 나오는 화면도 너무 썰렁해.. 이건 심각하게 수정을 고민해야 할 것 같아」
- 「지금 얘기하는 건 다 todo로 남기고 이번 작업 먼저 마무리」

기능은 스펙대로 움직인다. 화면의 모양이 문제다. 스펙 `docs/superpowers/specs/2026-11-07-review-practice-design.md`의 1, 2, 6이 그린 화면이다. PRD 「실패로 볼 것」 6(화면이 복잡하다)과 함께, 썰렁하지 않은 쪽도 봐야 한다.

## 할 일

1. **「다시 연습」 화면을 다시 기획한다(가장 큼):** 지금은 제목, 버튼 둘, 한 줄 설명뿐이다. superpowers brainstorming으로 다시 정한다. 같이 볼 것(아직 정하지 않은 생각들):
   - 화면을 따로 두지 않고 지난 상황과 모아 둔 문장을 한 화면에 보이기(예: 위에 모아 둔 문장 몇 줄, 아래에 최근 상황 몇 개, 「전체 보기」).
   - 라이언 그림이나 한마디를 둘지. 첫 화면은 라이언이 묻는 화면이다(PRD 「첫 화면」).
   - 첫 화면의 「다시 연습」 버튼과 어떻게 이어질지, 나중의 「이어 하기」, 「자유 대화」와 함께 어떻게 놓일지.
2. **지난 상황 목록:** 줄마다 「처음 한 날 11월 6일」이 되풀이되고 글자만 늘어서 밋밋하다. AI 추천(2026-11-07, 사용자 판단 전): 줄을 둥근 연회색 카드로 나누고 사이를 띄우기, 날짜는 제목 오른쪽에 「11월 6일」로 작게, 「처음 한 날」은 목록 위에 한 번만, 줄 끝에 「›」.
3. **모아 둔 문장 목록:** 2와 같은 카드 모양으로 맞춘다. 「빼기 ✕」의 자리와 크기도 다시 본다.
4. 바꾸기 전에 화면 초안을 브라우저로 보여 주고 고르게 한다(이번 brainstorming에서 그렇게 했다). 폰에서 다시 확인한다.
5. **상황 주제 목록과 맞추기 (2026-11-07 situation-topics 카드가 더함):** 상황 정하기에 주제별 「목록에서 고르기」 화면이 생긴다(`docs/superpowers/specs/2026-11-07-situation-topics-design.md` 2의 3). 그 카드도 2, 3과 같은 모양으로 맞춘다. 「지난 상황」 목록에 주제를 보이거나 주제별로 나눌지도 여기서 본다(그 스펙 「미룬 것」). 역할극 기록에는 주제(`topic`)가 남고, 주제가 없는 지난 기록은 「그 밖의 상황」이다.
6. **첫 화면 버튼 이름 (2026-11-07 situation-topics 카드가 더함):** 사용자가 폰을 보며 말했다.
   - 「역할극이 맞아? 상황극이 더 맞는 거 아닌가? 극이라..」
   - 「첫 화면은 상황 역할극이라고 나오네... 딱 보면 딱 알아볼 수 있나?」
   - 「다시 연습도 다시 연습 그러면 무슨 말인지.. 해 보지 않고서는 뭔지 모를 거 같은데」
   - 「상황 설정 연습하기라든가...」, 「설정 상황 연습하기가 맞나?」

   AI 추천(사용자 판단 전):
   - 「설정」은 앱의 설정 메뉴로 읽힐 수 있어 피한다.
   - 기능의 종류(역할극, 다시 연습) 대신 하는 일을 이름으로 쓰고, 밑에 한 줄 설명을 붙인다.
     - 예: 「새 상황으로 대화하기」, 밑에 「상황을 정하면 라이언과 영어로 주고받아요」
     - 예: 「했던 것 다시 연습하기」, 밑에 「지난 상황과 모아 둔 문장을 다시 말해 봐요」
   - 화면 초안을 브라우저로 나란히 보여 주고 고르게 한다.
   - 앱 안의 「역할극」 글은 「역할극으로」, 「역할극을 그만둘까요?」, 「하던 역할극은 아직 이어 할 수 없어요.」와 첫 화면 「상황 역할극」이다(2026-11-07 기준). PRD와 스펙의 낱말은 정한 뒤 함께 맞춘다. 코드 이름(`roleplay`)은 그대로 둔다.
   - 그 뒤 사용자: 「밑에 부연 설명이 나오면 .. 했던 것 다시 연습하기보다는.... 복습하기 또는 다시 연습하기 이런 식 어때?」 AI는 「복습하기」를 추천했다(공부 앱에서 흔한 말이라 바로 알아보고 짧다, 「다시 연습하기」는 지금 이름과 거의 같다). 사용자가 「응 적어 줘」라고 했다. 지금의 안:
     - 「대화 연습하기」, 밑에 「상황을 정하면 라이언과 영어로 주고받아요」
     - 「복습하기」, 밑에 「지난 상황과 모아 둔 문장을 다시 말해 봐요」
     - 화면 초안을 볼 때 이 안으로 그리고, 사용자가 화면에서 최종으로 정한다.
