main 세션은 도는 카드에 이 규칙을 전했고 Claude Code 메모리에 적었다. 메모리는 이 저장소의 Claude 세션만 읽고 무게도 규칙보다 가볍다.

## 할 일

1. `AGENTS.md` 「세션과 worktree: 오르카로 나눈다」에 넣는다.
   - **worktree 세션(카드):** 사용자에게 직접 묻지 않는다. 질문(짧게, 추천과 함께)과 「머지 준비 됨」(PR 번호, 바뀐 것, 돌린 시험과 결과, 리뷰에서 고친 것과 남긴 것)을 main 세션에 보낸다. 사용자가 봐야 하는 화면 초안은 주소와 볼 곳을 보낸다.
   - **main 세션:** 받은 질문을 어느 카드의 것인지 밝혀 사용자에게 묻고, 답을 그대로 전한다. 여러 카드가 함께 기다리면 순서와 서로 기대는 것(예: 머지 뒤 서버를 다시 띄우면 다른 카드의 폰 시험이 끊긴다)을 정리하고, 「ㅇㅋ」 한 번으로 답할 수 있게 추천 하나를 붙인다. 카드 사이의 조정(서버를 누가 언제 쓰는지, 시험 포트, 머지 순서)은 main이 정해 알린다.
   - **머지:** 사용자가 main에서 승인하면 main이 `gh pr merge --merge`로 머지하고, 정리(fast-forward, 할 일 사본, 브랜치, 서버 다시 띄우기, 머지 뒤 확인, worktree 떼어 두기)는 카드에 맡긴다. 카드는 main이 전한 승인을 다시 사용자에게 묻지 않는다.
   - 「PR과 머지」 절의 「리뷰를 마치면 사용자에게 … 알리고 머지 결정을 기다린다」, 「PR을 열면 바로 알리고 머지 결정을 묻는다」 줄도 이 흐름에 맞게 고친다(카드는 main에 알린다).
   - 이유로 위 사용자의 말과 날짜를 적는다.
2. 메시지를 보내는 도구는 에이전트마다 다르다. `AGENTS.md`에는 「main 세션에 메시지로 보낸다」로 쓰고, Claude Code의 도구(`ListAgents`, `SendMessage`, 받는 이름에 붙는 `[ref]`)는 `CLAUDE.md`에 쓴다.
3. 규칙 문서라 PR로 올린다.
