## 왜 하나

2026-11-08 사용자가 폰에서 보고 말했다. 「들린 말: 이거 표시 안 해도 될 것 같은데, 그거 말고 일부만 보이고 클릭하면 확장 펼치기 되게 하는 게 나을 듯한데, 화면 복잡하지 않게」. 한 줄로 할지 두 줄로 할지 물어, main 세션이 한 줄을 추천했고 사용자가 「한 줄로 해 줘」라고 정했다.

지금은 내 말풍선과 끝 화면에 `들린 말: …`이 다 보인다(`app/src/screens/RoleplayScreen.tsx`의 `heardLine`, `heard`, `app/src/screens/EndScreen.tsx`의 `heard`).

## 할 일 (사용자가 정함)

1. 「들린 말:」 이름표를 뺀다.
2. 들린 말은 흐린 글씨 한 줄로만 보이고, 길면 「…」로 자른다.
3. 그 줄을 누르면 전체가 펼쳐지고, 다시 누르면 접힌다.
4. 대화 화면의 내 말풍선과 끝 화면(지난 상황, 복습 포함) 모두 같게 한다.
5. 이름표가 없어도 그 줄이 내 대사가 아니라 맥이 들은 말이라는 것을 알 수 있는지 폰에서 본다. 헷갈리면 작은 표시(예: 귀 모양)를 둘지 main 세션에 초안과 함께 묻는다.
