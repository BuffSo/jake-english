## 왜 하나

역할극 MVP(PR: feat/roleplay-mvp)에서는 맥 서버를 터미널에서 `uv run python -m je_server`로 띄운다. 맥을 다시 켜거나 터미널을 닫으면 서버가 꺼져, 집 밖에서 앱이 「맥에 연결할 수 없어요」만 보여 준다.

## 할 일

- 로그인할 때 서버를 띄우고, 죽으면 다시 띄우는 방법을 정한다(예: launchd 사용자 에이전트). 맥 설정을 바꾸는 일이라 사용자에게 먼저 묻는다.
- 서버는 맥의 Tailscale 주소에 붙는다(ADR-0007). Tailscale이 서버보다 늦게 뜨면 주소에 붙지 못하므로, 기다렸다가 다시 시도하는지 본다.
- Tailscale 맥 앱은 로그인한 뒤에만 돈다(비공개 메모 참고). 맥이 다시 켜지면 로그인할 때까지 집 밖에서 붙지 못한다는 것을 사용자에게 알린다.
- 로그는 시간과 개수만 남긴다(`REVIEW.md` 「녹음 처리」).
