# TODO: 선생님 라이언의 답이 서버 안의 말(「짚을 곳」)을 학습자에게 하지 않게

> 작성: 2026-11-08
> 상태: **완료** (2026-11-08 server-small-fixes 카드, `fix/server-small-fixes`). `ASIDE_SYSTEM`에 갈라 낸 결과와 지시문의 갈래 이름을 말하지 않는 규칙, 앱에 바라는 말을 받는 갈래를 넣었다. 실제 소넷으로 고치기 전과 뒤를 견주고(`check_ryan_wording.py`), 학습자 목소리 한국어 녹음 둘을 시험 서버에 보냈다.

## 왜 하나

2026-11-08 사용자가 폰에서 역할극의 내 차례에 대사 대신 한국어로 앱에 바라는 것을 말했다. 서버는 이것을 대사와 다른 말로 맞게 가렸고(`aside`, 한국어), 선생님 라이언(글쓰기 모델, `prompts.ASIDE_SYSTEM`)이 한국어로 답했다. 그런데 답이 「대사와 상관없는 말로 들려서 따로 짚을 곳이 없어요」처럼 시작했다. 「짚을 곳」은 서버가 평가에 쓰는 자료의 이름이라 학습자에게는 뜻이 없다.

평가 말(하이쿠, `FEEDBACK_SYSTEM`)에서 같은 문제(「짚을 것이 없어요」)를 PR #32로 고쳤다. 선생님 라이언의 지시문에는 같은 규칙이 없다.

## 할 일

1. `ASIDE_SYSTEM`에 PR #32와 같은 규칙을 넣는다: 받은 자료나 설명이 없다는 것을 학습자에게 말하지 않는다. 「짚을 것」, 「대사와 상관없는 말로 들렸다」 같은 분류 결과를 그대로 말하지 않고, 학습자가 한 말에 바로 답한다(묻는 말이면 짧게 답하고, 다시 해 보자고 한다).
2. 앱에 바라는 것을 말한 경우(기능 요청, 불평)도 받는다. 예: 「좋은 생각이에요. 지금은 대사를 말해야 다음으로 가요.」처럼 짧게 받고 다시 해 보자고 한다. 예문은 지어낸다.
3. 실제 소넷으로 지어낸 한국어 녹음 몇 개를 보내 확인한다(`docs/guide/DEVENV_폰없이_녹음_시험하기_20261108.md`). 몇 번 부를지와 비용을 먼저 한 줄로 알린다.
4. 함께 볼 것: `20261108_10_todo_teacher_answer_cut_without_error.md`(같은 답의 끊김), offscript-aside 스펙 `docs/superpowers/specs/2026-11-07-offscript-aside-design.md`.
