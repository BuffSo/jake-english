## 왜 하나

2026-11-08 사용자가 말했다. 「요즘은 보통 예약을 많이 하잖아. 전화 예약을 했을 수도 있고 온라인 예약을 했을 수도 있고, 그 가정하에 호텔 체크인 해 보는 것도 괜찮을 것 같아. 하와이 씨푸드 레스토랑 같은 곳도 예약 안 하고 갔을 때 예약했냐고 직원이 물어보고, 뭐 이런 상황도 미리 만들어 보자. 기존 상황에 추가해 줘.」

지금 목록(`server/je_server/topics.py`의 `usa`)의 「뉴욕 호텔 체크인」(`u-hotel-checkin`)은 이미 예약한 방에 체크인하는 대본이다(「김 이름으로 예약했어요」). 그래서 새 호텔 대본은 예약을 어떻게 했는지가 대화에 드러나게 한다(main 세션 추천).

## 할 일

1. **호텔 체크인(예약 확인):** 온라인이나 전화로 예약하고 체크인한다. 예약을 어떻게 했는지와 확인할 것(확인 번호, 몇 박, 방 종류 등)이 대화에 나온다. 기존 「뉴욕 호텔 체크인」과 겹치지 않게 장소와 흐름을 다르게 한다. 기존 대본은 그대로 둔다.
2. **하와이 해산물 식당(예약 없이):** 예약하지 않고 갔는데 직원이 「예약하셨어요?」라고 묻는다. 자리가 있는지, 얼마나 기다리는지, 이름을 올려 두는 것 같은 흐름이다.
3. 대본 규칙을 지킨다: 목록 설명에 든 사실만 쓴다(`REVIEW.md` 「목록 대본의 사실」, PR #34), 한 덩어리 말을 나누면 첫 토막에 뒤에 더 있다는 표시를 둔다(PR #42), 통역 한국어도 함께 쓴다(PR #39). 실제 가게 이름을 쓸지는 사실을 확인할 수 있는지로 정한다.
4. 대본(영어와 통역)은 사용자가 보고 정한다. 초안을 main 세션에 보내고 답을 받은 뒤 커밋한다.
5. 새 목록 상황을 처음 고를 때 소희 소리와 세 줄 표시가 만들어지는지 확인한다.
