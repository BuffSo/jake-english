## 왜 하나

ADR-0004(PR #8)에서 라이언의 말을 외부 API(Claude)로 만들기로 정했다. 사용자는 속도를 걱정했지만, 재지 않고 추천대로 정했다. 그래서 ADR은 「녹음 평가가 몇 초 안에 오는지는 따라 말하기 스펙을 쓸 때 잰다」고 남겼다. 재려면 API 키가 있어야 하고, 시험 호출에 돈이 든다.

## 할 일

1. **API 키:** 받기 전에 사용자에게 묻는다(`AGENTS.md` 「새로 설치하거나 비용이 드는 일」). 키는 맥의 `.env`에만 두고 저장소와 앱에 넣지 않는다(ADR-0004).
2. **응답 시간 재기:** 시험 호출도 하기 전에 묻는다. 같은 입력으로 모델마다 잰다(Haiku 5.5, 생각하는 단계를 끈 Sonnet 5.5, effort를 낮춘 Opus 5.5).
   - 녹음 평가 한 번(받아쓴 글과 강세 분석 결과를 넣고 한국어 평가를 받는다)
   - 대화 한 턴(영어 대화 상대)
   - 잴 것: 첫 글자까지 걸린 시간, 전체 시간, 토큰 수와 비용
3. **결과를 스펙에 넣는다:** 따라 말하기 스펙에서 평가 모델을 고르고 PRD 열린 질문 2(몇 초 안에 와야 하는가)를 정할 때 쓴다.

## 같이 볼 것

- 평가가 매번 같은지는 모델 설정으로 지킬 수 없다(ADR-0004 「영향」). 평가를 재 볼 때 같은 입력을 몇 번 보내 짚는 곳이 달라지는지도 본다.
- 소희의 통역 글을 같은 API로 만들지(ADR-0004 「영향」, AI 추천)
