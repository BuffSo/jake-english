## 사용자가 정한 것 (2026-11-07)

- 앱은 지금 이 맥 서버에서만 돌아가니, 남에게 보여 줄 시연 영상을 만든다. 활용도는 영상을 본 뒤 정한다.
- 에뮬레이터에서 앱을 실제로 돌리는 화면을 녹화한다. 영상은 저장소에 넣지 않는다.
- 사용자 대사도 제이크 목소리가 말한다. 사용자는 따로 할 것이 없고, AI가 시나리오를 만들어 진행한다.
- 나머지는 main 세션 추천대로 한다.
  - 아는 사람에게 보여 주는 용도다. 제이크 얼굴과 목소리가 나오므로 공개로 올리는 것은 따로 정한다.
  - 새 상황 하나로 역할극을 하고, 끝 화면의 연습까지 보여 준다. 「다시 연습」 화면은 지난 기록의 실제 문장이 보여서 넣지 않는다.
  - 별도 카드에서 만든다.

## main 세션이 확인한 것 (2026-11-07)

- 지금 떠 있는 에뮬레이터(다른 프로젝트의 AVD, 화면과 소리 없이 띄움)는 다른 세션 것이라 쓰지 않는다. 받아 둔 arm64 이미지로 데모용 AVD를 새로 만든다(새로 받을 것 없음). 그 에뮬레이터에서 맥 서버(Tailscale 주소 8787)에 붙는 것을 확인했다.
- 에뮬레이터의 화면 녹화 기능으로 소리까지 담는 것을 먼저 시험한다.
- 제이크 목소리를 에뮬레이터 마이크로 넣는 방법을 정한다. 맥에 가상 오디오 장치를 새로 설치해야 하면 먼저 묻는다.
- 역할극 한 번에 API 비용이 몇 센트 든다.
