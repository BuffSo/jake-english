# TODO: 대사의 한국어 번역(통역) 보여 주기

> 작성: 2026-11-06 (practice-midway 카드, 폰에서 써 보고)
> 상태: **완료** (2026-11-06 korean-translation 카드, PR #24)

## 왜 하나

2026-11-06 사용자가 practice-midway의 앱을 폰에서 써 보고 「한국어 번역은 없네?」라고 했다.

- 지금 앱에는 대사의 뜻을 한국어로 보여 주는 곳이 없다. 세 줄 표시는 영어 원문, 한글 발음, 읽는 법이고, 뜻은 없다.
- PRD 「통역」에는 「라이언의 영어 대사를 못 알아들으면 소희가 한국어로 통역한다(AI 판단)」가 있다. 소희는 통역사이고, 설명하거나 가르치지 않는다(PRD 「목소리와 역할」).
- 첫 판을 정할 때 사용자가 소희의 통역을 뺐다(말하기 스펙 목표 6, 「미루는 것」).
- 사용자는 이번 PR(처음엔 평범하게, 역할극 중 연습)에 넣지 않고 다음 PR로 하기로 했다(AI 추천을 받아들임). 번역 글을 만들려면 서버를 고쳐야 하는데, 그때 서버는 follow-feedback 카드가 고치고 있었다.
- 2026-11-06 phone-test-fixes 카드(PR #20)에서 폰의 역할극 화면을 보며 다시 말했다: 「여기 통역이나 한국어로 풀어줘야 할텐데 소희를 이용할 수도 있고」. 말풍선에 「라이언」, 「내 차례」 이름을 붙인 뒤에 나온 말이다. PR #20에는 넣지 않았다(다른 일이고 서버와 스펙이 필요하다).

## 정할 것 (다음 PR의 스펙에서 사용자와 정한다)

- 어느 대사에 붙일지: 라이언 대사만(PRD 그대로), 내 대사도(예: 「읽는 법 보기」 안에 뜻 한 줄).
- 어떻게 보여 줄지: 글만, 소희 목소리로도. 처음부터 보여 주지 않고 원할 때만 보이는 것은 PRD 「한국어 해석: 살짝 곁들인다. 처음부터 보여 주지 않고, 원할 때 소희가 통역한다」를 따른다.
- 끝 화면의 주고받은 말에도 붙일지.
