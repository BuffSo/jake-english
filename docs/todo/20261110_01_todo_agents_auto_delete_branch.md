## 무엇을

2026-11-10 사용자 「ㅇㅋ」로 GitHub 저장소 설정 「Automatically delete head branches」를 켰다. 머지하면 GitHub가 그 PR의 원격 브랜치를 지운다. 머지가 끝난 옛 원격 브랜치 77개는 사용자가 한 번에 지웠다.

`AGENTS.md` 「원격 저장소」에 squash와 rebase 머지를 끈 설정이 적혀 있으니, 같은 자리에 이 설정도 적는다.

- 머지한 브랜치의 원격 쪽은 GitHub가 지운다. 에이전트가 원격 브랜치를 지우지 않는다는 규칙은 그대로다.
- 머지하지 않고 닫은 PR의 브랜치는 저절로 지워지지 않는다. 전처럼 사용자가 GitHub에서 지운다.
- 카드의 정리에서 `git fetch --prune`을 하면 로컬의 원격 브랜치 표시도 정리된다.

규칙 문서라 PR로 올린다.
